# Experiment: Synset Linguistic Audit

| | |
|---|---|
| **Date** | 2026-02-24 |
| **Status** | Design phase — review framework defined, implementation pending |

---

## Motivation

AWN4 contains 109,901 synsets generated by LLM translation from Open English WordNet 2024. Previous experiments have addressed specific issues — polysemy disambiguation (indistinguishable lemma sets), diacritics mismatches, POS errors. But no experiment has yet asked the fundamental question:

> **Is the linguistic content of each synset — its lemmas, definition, and examples — sound Arabic?**

This experiment designs a rigorous linguistic review framework by first cataloguing every piece of linguistic information present in a synset, then systematically deriving every question an Arabic linguist would ask about that information.

### What This Experiment Is NOT

This is not a repeat of the `linguist_review/` experiment. That experiment built a 262-line mega-prompt covering 11+ axes and reviewing one synset at a time (~2,000 output tokens per synset). At 109,901 synsets, that approach doesn't scale.

This experiment takes a different approach: **decompose the review into independent, parallelizable checks** — some fully automated, some LLM-assisted — each asking a focused question.

### Relationship to Previous Work

| Experiment | What It Reviewed | What It Left Unreviewed |
|---|---|---|
| `prefilter/` | Dictionary attestation, POS, diacritics, duplicates | Definition quality, example quality, semantic relations |
| `polysemy_reviews/` | Lemma disambiguation (adding synonyms) | Whether existing lemmas/definitions are correct |
| `linguist_review/` | Broad 11-axis review (prototype only) | Never scaled beyond 100 synsets |
| **This experiment** | All linguistic content systematically | — |

## Part 1: Anatomy of an AWN4 Synset

### 1.1 Data Format

AWN4 uses **WN-LMF 1.4** (Global WordNet Association standard). The XML has two main element types:

- **`<LexicalEntry>`** — Links an Arabic lemma to one or more synsets via `<Sense>` elements
- **`<Synset>`** — A concept: definition + examples + semantic relations

```
LexicalEntry (آثر, verb)
  ├── Sense n=1 ──→ Synset awn4-01830440-v ("to prefer")
  └── Sense n=2 ──→ Synset awn4-02405179-v ("to favor/promote over others")
```

### 1.2 Fields Present in Every Synset

| # | Field | Source Element | Always Present | Example |
|---|---|---|---|---|
| 1 | Synset ID | `<Synset id="">` | Yes | `awn4-00001740-a` |
| 2 | Part of Speech | `<Synset partOfSpeech="">` | Yes | `n`, `v`, `a`, `r` |
| 3 | ILI link | `<Synset ili="">` | Yes (empty for 3,123 AWN4-specific synsets) | `i1` |
| 4 | Arabic definition | `<Definition>` | Yes (exactly 1) | `يمتلك الوسائل أو المهارة...` |
| 5 | Arabic examples | `<Example>` | No — **76.1% have zero** | `قادر على السباحة` |
| 6 | Semantic relations | `<SynsetRelation>` | No — varies (0 to many) | `hypernym`, `hyponym`, etc. |

### 1.3 Fields Present via LexicalEntry → Sense → Synset

| # | Field | Source | Example |
|---|---|---|---|
| 7 | Lemma written form | `<Lemma writtenForm="">` | `آثر` |
| 8 | Lemma POS | `<Lemma partOfSpeech="">` | `v` |
| 9 | Lemma script | `<Lemma script="">` | `Arab` (always) |
| 10 | Polysemy rank | `<Sense n="">` | `1`, `2` (when a lemma maps to multiple synsets) |

### 1.4 Fields Defined in DTD but Absent in AWN4

These fields exist in the WN-LMF 1.4 standard but AWN4 does not populate them. They represent potential **enrichment targets** for future work:

| Field | What It Would Add | Arabic Relevance |
|---|---|---|
| `Pronunciation` | IPA transcription | Critical — Arabic pronunciation depends on diacritics |
| `Form` | Morphological variants (plural, dual, feminine) | Very high — Arabic morphology is rich |
| `SyntacticBehaviour` | Verb subcategorization frames | High — Arabic verbs differ by transitivity and preposition |
| `SenseRelation` | Antonyms, derivations, pertainyms | High — Arabic has systematic derivational morphology |
| `Count` | Corpus frequency | Medium — would help prioritize review |
| `Tag` | Morphological tags | Medium — root, pattern, etc. |
| `confidenceScore` | Per-element quality score | Would be useful for tracking review progress |

## Part 2: The 35 Review Questions

Organized by linguistic level. Each question targets a specific type of error that could exist in an AI-translated wordnet.

### Level 1: Lemma Quality (اللمات) — 9 Questions

These questions examine whether the Arabic words assigned to each synset are correct, appropriate, and complete.

#### Q1.1 — Is each lemma in the correct citation form?

**Convention:** Nouns → مفرد مُنكَّر (indefinite singular). Verbs → ماضٍ مجرد (past tense, base form). Adjectives → مذكر مفرد (masculine singular).

**What it catches:** Lemmas entered as plurals, feminines, or verbal nouns instead of citation forms.

**Automation potential:** High — morphological analyzers (CAMeL Tools, Farasa) can detect non-citation forms.

#### Q1.2 — Is the lemma fully and correctly vocalized (تشكيل)?

**What it catches:** Missing or wrong diacritics. In Arabic, diacritics can change meaning entirely:
- بَرَأَ (to create) vs بَرَّأَ (to acquit) vs بَرِئَ (to recover)

**Automation potential:** High — the `prefilter/` experiment already found 4,583 diacritics mismatches using dictionary comparison.

**Prior work:** `prefilter/` `DIACRITICS_MISMATCH` flag covers this partially (limited by dictionary coverage at 24.9%).

#### Q1.3 — Is each lemma MSA (فصحى)?

**What it catches:** Colloquial forms, overly archaic forms, raw unassimilated loanwords.

**Automation potential:** Medium — could use a register classifier, but borderline cases (مُعَرَّب words, technical terms) require judgment.

#### Q1.4 — Does each lemma actually denote *this specific sense*?

**Example:** The lemma عقد appears in 18 different synsets (contract, decade, bridge bid, etc.). For the "bridge bid" synset, is عقد really the right Arabic word, or was it a mechanical default?

**What it catches:** Polysemy errors — the lemma fits a *different* sense of the same root word.

**Automation potential:** Low — requires semantic understanding.

**Prior work:** `polysemy_reviews/` addresses this by adding *disambiguating* lemmas, but doesn't question whether the *existing* lemma is correct for the sense.

#### Q1.5 — Are the lemmas genuinely synonymous in this sense?

**Test:** Can each lemma substitute for the others in the same syntactic frame without changing the meaning?

**What it catches:** False synonyms — words that are semantically related but not interchangeable.

**Arabic-specific concern:** The Arabic linguistic tradition (following Ibn Jinni, al-Tha'alibi, Abu Hilal al-'Askari) holds that **true synonymy is rare** — every word carries a distinctive nuance (الفارق الدقيق). A synset claiming full synonymy between two Arabic words should be examined carefully.

**Automation potential:** Low — requires deep semantic and pragmatic knowledge.

#### Q1.6 — Is a key synonym missing?

**What it catches:** Gaps in the synonym set — a more common or more precise Arabic word exists but wasn't included.

**Automation potential:** Medium — dictionary lookups and embedding similarity can suggest candidates.

**Prior work:** `polysemy_reviews/` adds disambiguating synonyms, which partially overlaps with this.

#### Q1.7 — Is any lemma a calque or awkward Arabization?

**What it catches:** Translation artifacts — lemmas that are literal translations of English words rather than established Arabic terms.

**Automation potential:** Medium — could detect multi-word lemmas that match English compound patterns.

#### Q1.8 — For verbs: is the correct binyan (وزن) used?

**Arabic-specific:** Arabic verbs have 10+ derived forms (binyanim/أوزان), each with different semantic implications:
- فَعَلَ (Form I: base) vs أَفْعَلَ (Form IV: causative) vs فَعَّلَ (Form II: intensive/causative)
- تَفَاعَلَ (Form VI: reciprocal) vs اِنْفَعَلَ (Form VII: reflexive/passive)

**What it catches:** Wrong verb form selected — e.g., using the base form when the causative is needed.

**Automation potential:** Medium — morphological analyzers can identify the binyan, but whether it's *correct for this sense* requires judgment.

#### Q1.9 — Are there duplicate or near-duplicate lemmas?

**What it catches:** Noise in the lemma set — two lemmas that differ only in diacritics, a trailing digit, or trivial spelling.

**Automation potential:** High — string similarity after normalization.

**Prior work:** `prefilter/` normalization functions partially address this.

### Level 2: Definition Quality (التعريف) — 8 Questions

These questions examine whether the Arabic definition is linguistically sound, semantically accurate, and stylistically appropriate.

#### Q2.1 — Is the definition grammatically correct Arabic?

**What it catches:** Syntax errors, agreement failures (gender, number, case), broken إعراب.

**Example of concern:** AI-translated definitions may produce grammatically unusual constructions that a native speaker would not write.

**Automation potential:** Medium — grammar checkers exist but are imperfect for Arabic.

#### Q2.2 — Is the definition non-circular?

**What it catches:** Definitions that use the word being defined (or a trivially related form).

**Concrete example from AWN4:**
```
Synset: awn4-00492026-a
Lemma: غير عادي
Definition: غير معتاد أو غير شائع أو غير عادي  ← defines "غير عادي" using "غير عادي"
```

**Scale in AWN4:** A scan found **~10,168 synsets** where a lemma appears inside its own definition text. Not all are true circularity (the lemma might appear in a non-defining context), but this is a significant signal.

**Automation potential:** High — string matching of lemmas against definition text, with morphological expansion.

#### Q2.3 — Does the definition follow genus–differentia structure?

**The gold standard for lexicographic definitions:** "An X (genus) that Y (differentia)."
- Good: "حيوان ثديي مائي من فصيلة الحيتانيات" (a marine mammal of the whale family)
- Poor: "كبير ويعيش في البحر" (big and lives in the sea)

**What it catches:** Vague, overly broad, or structurally weak definitions.

**Automation potential:** Low — requires understanding definition structure.

#### Q2.4 — Is the definition a calque/literal translation from English?

**This is the single most likely systematic error in an AI-translated wordnet.**

**Concrete example from AWN4:**
```
Synset: awn4-01440837-a (adjective: "long" in temporal sense)
Definition: بالمعنى الزمني الأساسي؛ كونه أو يشير إلى مدة كبيرة نسبياً...
```

The phrase "بالمعنى الزمني الأساسي" is a word-for-word translation of the Princeton WordNet meta-annotation "In the primary temporal sense" — a lexicographer's note, not a definition. No Arabic dictionary would open a definition this way.

**Another common pattern:** "من أو ينتمي إلى" — a calque of "of or relating to" — appears in many adjective definitions:
```
Synset: awn4-00243558-a
Definition: من أو ينتمي إلى مجموعة عرقية خاصة من أصل أفريقي جنوب الصحراء الكبرى
```

**What it catches:** Un-Arabic phrasing, word order, or conceptual framing inherited from the English source.

**Automation potential:** Medium-High — pattern matching for known calque templates (e.g., "من أو ينتمي إلى", "بالمعنى الـ... الأساسي", "كونه أو يشير إلى"), plus LLM classification.

#### Q2.5 — Does the definition actually match the intended sense?

**What it catches:** Definition–sense mismatch. The definition might describe a related but different concept, especially when the English source synset has subtle sense distinctions.

**Automation potential:** Low — requires comparing definition semantics against the synset's position in the taxonomy.

#### Q2.6 — Is the definition appropriately specific?

**What it catches:** Over-specification (definition is so narrow it excludes valid instances) or under-specification (definition is so broad it covers sibling synsets too).

**Test:** Could this definition apply equally to a sibling synset (same hypernym, different sense)?

**Automation potential:** Low — requires contrastive analysis across sibling synsets.

#### Q2.7 — Are parenthetical domain markers correct?

**Pattern in AWN4:** Many definitions include a domain label in parentheses: `(علم النبات)`, `(قانون)`, `(الميثولوجيا الإسكندنافية)`.

**What it catches:** Wrong domain label, missing domain label where one is needed, or domain label that doesn't match the `domain_topic` relation.

**Automation potential:** High — cross-check parenthetical text against `domain_topic` SynsetRelation targets.

#### Q2.8 — Does the definition distinguish literal from figurative senses?

**Arabic-specific concern:** The Arabic lexicographic tradition carefully distinguishes حقيقة (literal meaning) from مجاز (figurative/metaphorical meaning). A definition should clarify which is intended.

**What it catches:** Figurative senses presented as literal, or mixed literal/figurative content in one definition.

**Automation potential:** Low — requires semantic understanding.

### Level 3: Example Quality (الأمثلة) — 6 Questions

#### Q3.1 — Does each example use the target lemma in the intended sense?

**What it catches:** Examples that use the word but illustrate a different sense.

**Automation potential:** Medium — embedding similarity between example context and definition.

#### Q3.2 — Is the example grammatically correct Arabic?

**What it catches:** Syntax errors, broken agreement, unnatural word order.

**Automation potential:** Medium — grammar checkers.

#### Q3.3 — Is the example natural and idiomatic?

**What it catches:** Translated/artificial examples that no Arabic speaker would say.

**Concrete example from AWN4:**
```
Synset: awn4-00100143-a (adjective: "live/active")
Example: الخام الحي هو خام غير مستخرج  ← "live ore is unextracted ore"
```
This reads as a direct translation of an English example.

**Automation potential:** Low-Medium — perplexity scoring could flag unnatural sentences.

#### Q3.4 — Is the example culturally appropriate?

**What it catches:** Examples referencing foreign cultural contexts that don't resonate with Arabic speakers.

**Concrete example from AWN4:**
```
Synset: awn4-09609728-n (آدم / Adam)
Definition: (العهد القديم) في الميثولوجيا اليهودية المسيحية؛ أول إنسان...
```
Adam is a major figure in Islamic tradition (mentioned 25 times in the Quran). Labeling him as "(Old Testament) Jewish-Christian mythology" is culturally inappropriate for an Arabic wordnet.

**Automation potential:** Medium — certain patterns (mythology labels for Islamic figures) are detectable.

#### Q3.5 — Are there enough examples?

**Scale of the problem:** 76.1% of synsets (83,664) have **zero examples**. For ambiguous synsets, this is particularly problematic — examples are the primary way users understand which sense is meant.

**Automation potential:** High — simple count check.

#### Q3.6 — Do the examples show different syntactic patterns?

**What it catches:** All examples using the same construction, missing important usage patterns.

**Arabic-specific:** For verbs, examples should show different transitivity patterns, preposition frames, and morphological forms (active/passive, imperfect/perfect).

**Automation potential:** Low — requires syntactic parsing.

### Level 4: Part of Speech (القسم النحوي) — 3 Questions

#### Q4.1 — Is the POS tag correct?

**Common error patterns in AWN4:** Masdars (verbal nouns) tagged as nouns when they should be verbs, or vice versa. Participles (اسم فاعل / اسم مفعول) tagged as adjectives vs. nouns.

**Prior work:** `prefilter/` `POS_MISMATCH` flag found 3,915 cases.

**Automation potential:** High — morphological analyzers can detect POS.

#### Q4.2 — Is the POS consistent between synset and all its lemmas?

**What it catches:** A noun synset with a verb lemma, or vice versa.

**Automation potential:** High — simple cross-check.

#### Q4.3 — For verbal nouns (مصادر): is the categorization correct?

**Arabic-specific:** Arabic verbal nouns (مصادر) straddle the noun/verb boundary. قراءة (reading) is both a noun and a verbal noun. The correct POS depends on how it's used in the synset.

**Automation potential:** Medium — morphological analysis can identify masdars, but the correct POS requires understanding the synset's semantic role.

---

### Level 5: Semantic Relations (العلاقات الدلالية) — 5 Questions

AWN4 inherits its relation structure from OEWN. These relations were not translated — they map to Arabic synsets that correspond to the English synsets. The questions here check whether the *Arabic* interpretation of these relations holds.

#### Q5.1 — Is the hypernym correct?

**Test:** "Is [this synset] a kind of [hypernym]?" — the most basic semantic relation.

**Prior work:** `arabic_ontology_comparison/` found ~6% genuine agreement, ~3% genuine disagreement, ~57% untestable when comparing AWN4 hypernym chains against the Arabic Ontology.

**Automation potential:** Medium — LLM can evaluate "is X a kind of Y" for Arabic concepts.

#### Q5.2 — Is the hypernym at the right level of generality?

**What it catches:** Hypernym too broad (e.g., → "entity") or too narrow (→ sibling synset).

**Automation potential:** Low — requires understanding the taxonomy structure.

#### Q5.3 — Are meronymy relations valid?

**Test:** "Is [part] genuinely a part of [whole]?"

**Automation potential:** Medium — LLM evaluation.

#### Q5.4 — For verbs: are entailment/cause relations correct?

**What it catches:** Wrong causal or entailment claims between verb synsets.

**Automation potential:** Low — requires deep semantic understanding.

#### Q5.5 — Are domain_topic assignments appropriate?

**What it catches:** Synsets assigned to wrong topical domains.

**Concrete example from AWN4:**
```
Synset: awn4-00002312-a (adjective: "abaxial" — directed away from the axis)
Domain: awn4-06047178-n (biology)
```
This is correct. But inherited domain assignments from English may not always apply to the Arabic concept.

**Automation potential:** Medium — cross-check domain label against definition content.

### Level 6: Arabic-Specific Linguistic Properties (خصائص عربية) — 6 Questions

These questions address linguistic features that are particularly important for Arabic but have no direct counterpart in the English source.

#### Q6.1 — What is the root (جذر)? Does it align with the meaning?

**Arabic-specific:** Arabic words derive from trilateral/quadrilateral roots that carry core semantic content. The root ك-ت-ب carries the meaning "writing" across كتاب (book), كاتب (writer), مكتبة (library), etc.

**What it catches:** Lemmas whose root semantics don't align with the synset's meaning — a signal of a wrong lemma choice.

**Automation potential:** High — root extraction is well-supported by morphological tools.

#### Q6.2 — For verbs: what is the transitivity and preposition frame?

**Arabic-specific:** Arabic verbs change meaning with different prepositions:
- رغب في (to desire) vs رغب عن (to turn away from)
- بحث عن (to search for) vs بحث في (to research)

This information is **completely absent** from AWN4 (the `SyntacticBehaviour` field is unused).

**What it catches:** Missing valency information that is essential for correct usage.

**Automation potential:** Medium — could be partially extracted from examples and definitions.

#### Q6.3 — Is the morphological pattern (وزن) correctly identified?

**Arabic-specific:** Arabic words follow predictable patterns (فَعَلَ, فَاعِل, مَفْعُول, etc.) that encode grammatical and semantic information.

**What it catches:** Lemmas whose stated/implied pattern doesn't match their actual form.

**Automation potential:** High — morphological analyzers.

#### Q6.4 — Are there known collocations (متلازمات لفظية)?

**What it catches:** Missing fixed expressions or collocations that would help a user understand the word's usage.

**Example:** The word عقد (contract) collocates with أبرم (to conclude): أبرم عقداً. This collocation information is absent from AWN4.

**Automation potential:** Medium — corpus-based collocation extraction.

#### Q6.5 — Register/era: is this a classical, modern, or technical term?

**What it catches:** Missing usage labels. Is this word تراثي (classical), معاصر (modern), or تقني (technical)?

**Automation potential:** Medium — could use corpus frequency across classical vs. modern corpora.

#### Q6.6 — Is this concept culturally relevant to Arabic speakers?

**Concrete example from AWN4:**
```
Synset: awn4-02454645-n (ميكي ماوس / Mickey Mouse)
Definition: فأر خيالي تم إنشاؤه في أفلام الرسوم المتحركة بواسطة والت ديزني
```
Mickey Mouse is universally known — fine. But some OEWN synsets describe hyper-specific Western cultural concepts (certain board games, regional foods, obscure historical figures) that have no Arabic cultural grounding.

**What it catches:** Synsets that exist in AWN4 only because they existed in OEWN, with no relevance to Arabic speakers.

**Prior work:** `polysemy_reviews/` flags `CULTURALLY_IRRELEVANT` and `PROPER_NOUN_SKIP`.

**Automation potential:** Medium — could use ILI coverage + cultural keyword detection.

---

### Level 7: Cross-Synset Consistency — 3 Questions

These questions require comparing multiple synsets simultaneously — they cannot be answered by looking at one synset in isolation.

#### Q7.1 — Are sibling synsets (same hypernym) properly differentiated?

**What it catches:** Sibling synsets with overlapping definitions or identical lemma sets.

**Prior work:** `prefilter/` `DUPLICATE_SYNSETS` and `polysemy_reviews/` address the lemma overlap case. This question extends to definition overlap.

**Automation potential:** Medium — embedding similarity between sibling definitions.

#### Q7.2 — Is this synset a duplicate of another?

**What it catches:** Truly redundant synsets with the same meaning under different IDs.

**Prior work:** `polysemy_reviews/` `IDENTICAL_SENSES` flag.

**Automation potential:** Medium — requires semantic similarity, not just string matching.

#### Q7.3 — Is the definition style consistent with siblings?

**What it catches:** Inconsistent genus–differentia formatting across synsets that should follow the same pattern.

**Example:** All color adjective synsets should define colors in a consistent way. If "red" uses genus–differentia but "blue" uses a circular definition, that's an inconsistency.

**Automation potential:** Medium — LLM comparison of sibling definition styles.

## Part 5: Concrete Examples from AWN4

### Example A: Calque Definition (Q2.4)

```xml
<Synset id="awn4-01440837-a" ili="i7859" partOfSpeech="a">
  <Definition>بالمعنى الزمني الأساسي؛ كونه أو يشير إلى مدة كبيرة نسبياً أو أكبر من
  المتوسط أو مرور وقت أو مدة كما هو محدد</Definition>
  ...
</Synset>
```

**Problem:** "بالمعنى الزمني الأساسي" is a literal translation of "In the primary temporal sense" — a Princeton WordNet lexicographer's metalinguistic note. "كونه أو يشير إلى" calques "being or referring to." No Arabic dictionary would phrase a definition this way.

**What a native definition would look like:** "ممتدٌّ في الزمن؛ يوصف به ما طالت مُدَّته" (Extended in time; describes what is of long duration).

### Example B: Circular Definition (Q2.2)

```xml
<Synset id="awn4-00492026-a" ili="i2757" partOfSpeech="a">
  <Definition>غير معتاد أو غير شائع أو غير عادي</Definition>
  <!-- Lemma: غير عادي -->
</Synset>
```

**Problem:** The definition of "غير عادي" includes "غير عادي" as the third disjunct. This is textbook circularity.

### Example C: Culturally Inappropriate Framing (Q3.4)

```xml
<Synset id="awn4-09609728-n" ili="i87050" partOfSpeech="n">
  <Definition>(العهد القديم) في الميثولوجيا اليهودية المسيحية؛ أول إنسان وزوج حواء
  وأصل الجنس البشري</Definition>
  <!-- Lemma: آدم -->
</Synset>
```

**Problem:** Adam (آدم) is mentioned 25 times in the Quran and is considered the first prophet in Islam. Labeling him as "(Old Testament) Jewish-Christian mythology" erases the Islamic tradition entirely. An Arabic wordnet should at minimum use "(الأديان الإبراهيمية)" or reference the Quranic tradition.

### Example D: No Examples for Ambiguous Concept (Q3.5)

```xml
<Synset id="awn4-00017402-n" ili="i35564" partOfSpeech="n">
  <Definition>(علم النبات) كائن حي يفتقر إلى القدرة على الانتقال الحركي</Definition>
  <!-- Zero examples. Lemma: نبات.
       Without examples, how does a user know if this means "plant"
       in the general sense or a specific botanical sense? -->
</Synset>
```

### Example E: Full Verb Entry Structure (Q1.8, Q6.2)

```xml
<!-- LexicalEntry -->
<LexicalEntry id="awn4-e6ec8d14a09a7">
  <Lemma writtenForm="آثر" partOfSpeech="v" script="Arab"/>
  <Sense id="awn4-s4540356775b9" synset="awn4-01830440-v" n="1"/>
  <Sense id="awn4-s701369890e11" synset="awn4-02405179-v" n="2"/>
</LexicalEntry>

<!-- Sense 1 -->
<Synset id="awn4-01830440-v" ili="i30858" partOfSpeech="v">
  <Definition>أحب أكثر؛ قدر قيمة أعلى</Definition>
  <Example>بعض الناس يفضلون التخييم على البقاء في الفنادق</Example>
  <SynsetRelation relType="hypernym" target="awn4-01781131-v"/>
</Synset>
```

**Observation:** آثر is Form IV (أَفْعَلَ pattern) meaning "to prefer/favor." The definition says "أحب أكثر" (loved more) which is a comparative, not a definition. The example uses "يفضلون" (they prefer) — a *different* verb (فضّل, Form II) — not the lemma آثر. This raises Q3.1 (example doesn't use the target lemma) and Q2.4 (definition may be a calque of the English gloss "like better").

## Assumptions & Scope

### What this experiment assumes
- **The synset inventory (from OEWN) is the starting point.** We are not questioning whether 109,901 synsets is the right number — we are reviewing the quality of the Arabic linguistic content assigned to each synset.
- **The semantic relation structure (hypernym/hyponym/meronym) is inherited from OEWN and largely correct.** We may flag Arabic-specific issues but are not re-engineering the taxonomy.

### What this experiment does NOT assume
- **That the AI translation is correct.** This is the core hypothesis being tested.
- **That all OEWN concepts are relevant to Arabic.** Cultural relevance is explicitly reviewed (Q3.4, Q6.6).
- **That the previous experiments covered everything.** The polysemy and prefilter work addressed specific slices; this experiment aims for comprehensive coverage.
