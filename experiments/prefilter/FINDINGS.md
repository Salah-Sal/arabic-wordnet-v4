# AWN4 Dictionary Pre-Filter — Approach & Findings

**Date:** 2026-02-23
**Script:** `experiments/prefilter_dict.py`
**Report:** `experiments/prefilter_report.json` (66 MB)

---

## Motivation

AWN4 (109,901 synsets) was generated by LLM translation from Open English WordNet 2024. Before investing in expensive LLM-based linguist review, we need an automated pre-filter to flag mechanical errors that don't require human judgment. The arabic-dictionaries SQLite database (94,537 entries from المعجم الوسيط and المعجم الكبير) serves as the authoritative ground truth.

No bridge previously existed between the two systems. This script creates the first connection.

---

## Approach

### Data Sources

| Resource | Size | What It Provides |
|----------|------|------------------|
| `output/awn4.xml` | 72 MB, 109,901 synsets, 124,768 lexical entries | Lemmas, POS, definitions, relations |
| `arabic_dict.db` | 86 MB, 94,537 entries, 58,476 distinct headwords | Headwords (diacritized), roots, POS, definitions, examples |

### Normalization Strategy

AWN4 lemmas and DB headwords are normalized to a **canonical form** for matching:

1. Strip Arabic diacritics (tashkeel: `\u064B-\u065F`, superscript alef: `\u0670`, Quranic marks: `\u06D6-\u06ED`)
2. Normalize alef variants: أ/إ/آ → ا
3. Normalize alef maqsura: ى → ي
4. Remove tatweel (ـ), trailing disambiguation digits, definite article (ال)

This follows the patterns established in `find_matches.py` and `qc_json.py`, extended with alef maqsura normalization and article stripping for broader matching.

### Architecture

The script runs in 5 phases:

1. **Load dictionary DB into memory** — single SQL query, builds two in-memory dicts (canonical lookup + raw lookup for diacritics comparison). ~24 MB memory.
2. **Stream-parse AWN4 XML** — `ET.iterparse` with `elem.clear()` for memory efficiency. Builds synset→lemmas and synset→metadata dicts.
3. **Run 6 checks per synset** — all O(1) dict lookups, no DB queries during checking.
4. **Cross-synset duplicate detection** — fingerprint synsets by their normalized lemma set.
5. **Write JSON report + print summary**.

Total runtime: **3.6 seconds**.

### Checks Implemented

| # | Flag | Scope | Description |
|---|------|-------|-------------|
| 1 | `LEMMA_NOT_FOUND` | per-lemma | Lemma has no match in dictionary after normalization |
| 2 | `ALL_LEMMAS_MISSING` | per-synset | Every lemma in a synset is not found — zero dictionary evidence |
| 3 | `POS_MISMATCH` | per-lemma | AWN4 POS doesn't match any DB entry's POS for that headword |
| 4 | `ROOT_INCONSISTENCY` | per-synset | Lemmas in same synset have no shared root (different etymological families) |
| 5 | `DIACRITICS_MISMATCH` | per-lemma | AWN4 vocalization differs from dictionary's vocalization |
| 6 | `DUPLICATE_SYNSETS` | cross-synset | Different synset IDs share identical normalized lemma sets |

POS mapping: `n→{noun, proper_noun}`, `v→{verb}`, `a→{adj}`, `r→skip` (adverbs not in classical dictionaries).

## Detailed Findings

### Finding 1: Polysemy Explosion (DUPLICATE_SYNSETS)

**5,378 groups involving 12,496 synsets** share identical lemma sets. This is the most actionable finding.

Two sub-categories:

| Type | Groups | Synsets | Description |
|------|--------|---------|-------------|
| Single-lemma polysemy | 3,790 | 8,966 | Same Arabic word is the sole lemma in multiple synsets |
| Multi-lemma duplicates | 1,588 | 3,530 | Identical lemma sets across different synsets |

**Top single-lemma polysemy cases:**

| Lemma | Synsets | Problem |
|-------|---------|---------|
| عقد | 18 | 18 noun senses all translated to just "عقد" |
| رفع | 15 | 15 verb senses all translated to just "رفع" |
| رأس | 13 | 13 noun senses all translated to just "رأس" |
| قاعدة | 10 | 10 noun senses |
| سحب | 10 | 10 verb senses |
| شبكة | 9 | 9 noun senses |
| نقطة | 9 | 9 noun senses |
| نقل | 9 | 9 verb senses |

**Top multi-lemma duplicate cases:**

| Lemma Set | Synsets | Problem |
|-----------|---------|---------|
| {عزل, فصل} | 7 | 7 verb senses indistinguishable by lemmas |
| {احتقار, ازدراء} | 6 | 6 noun senses |
| {تماماً, كلياً} | 6 | 6 adverb senses |
| {حل, فك} | 6 | 6 verb senses |
| {ربط, قيد} | 6 | 6 verb senses |

**Interpretation:** The LLM translator defaulted to the most common Arabic translation for each English word without adding disambiguating synonyms. A user looking at AWN4 would see 18 different synsets all labeled "عقد" with no way to tell them apart from the lemmas alone. Each of these needs at least one additional lemma or a distinctive qualifier.

**Priority:** These are prime candidates for **Stage 4 (polysemy-cluster review)** — feed all synsets sharing a lemma into the LLM reviewer together with dictionary data so it can add disambiguating synonyms.

### Finding 2: Diacritization Errors (DIACRITICS_MISMATCH)

**4,583 synsets** have lemmas whose vocalization differs from the dictionary.

Examples of real errors caught:

| AWN4 Form | Dictionary Form | Issue |
|-----------|-----------------|-------|
| بَرَّأَ | بَرَأَ | Shadda on raa changes verb from Form II to Form I — different meaning |
| أغلّ | أَغَلَّ | Missing fatha on alef and ghayn |
| رامٍ | رَامٍ | Missing fatha on raa |
| فَلْقَة | الفِلْقَةُ | Different vowel pattern (fatha vs kasra) |
| مُنَفِّذ | المَنْفَذُ | Different morphological pattern entirely (ism fa'il vs ism makan) |

**Interpretation:** These are directly fixable — the dictionary vocalization is authoritative. An automated pass could correct many of these by replacing AWN4 diacritics with the dictionary's form, though human review is needed for cases where multiple dictionary forms exist.

### Finding 3: POS Mismatches — Three Patterns

**3,915 synsets** have at least one lemma where the AWN4 POS contradicts the dictionary.

**Pattern A — Real errors:**
Some words are genuinely tagged with the wrong POS. These need correction.

**Pattern B — Masdar ambiguity (most common):**
AWN4 tags verbal nouns (masdars) as nouns, while the dictionary lists the verb form. Both are linguistically correct — تذلُّل IS a noun (masdar of تذلَّل). This pattern accounts for a large share of noun-vs-verb mismatches and is informational rather than erroneous.

Examples: تذلل (AWN4=noun, DB=verb تذلَّل), تملق (AWN4=noun, DB=verb تملَّق)

**Pattern C — DB coverage gaps:**
Adjective forms like جلي (clear), قائم (standing), موجود (existing) are active participles used as adjectives. The DB catalogues them as nouns or verbs but not as adjectives, so the mismatch is a DB limitation rather than an AWN4 error.

### Finding 4: ROOT_INCONSISTENCY — Mostly False Positives

**9,196 synsets** have lemmas from different trilateral roots. However, spot-checking reveals this is **expected behavior** for synonym sets:

| Synset | Lemmas | Roots | Real Issue? |
|--------|--------|-------|-------------|
| awn4-00617127-n | ترميز, تشفير | رمز, شفر | No — legitimate synonyms |
| awn4-10576945-n | ساذج, مغفل | سذج, غفل | No — legitimate synonyms |
| awn4-02608455-v | تسرع, تعجل | سرع, عجل | No — legitimate synonyms |
| awn4-14781933-n | زغب, وبر | زغب, وبر | No — both mean "fine hair/down" |
| awn4-03595493-n | حافظة, غلاف | حفظ, غلف | No — both mean "case/cover" |

**Conclusion:** Different roots within a synset is normal — synonyms come from different etymological families. This flag should be treated as **informational context** for reviewers rather than an error signal. It becomes useful in Stage 2 (root-family batching) where the root data helps organize the review.

## Limitations

1. **DB coverage**: Only 2 of 37+ dictionaries are in the SQLite DB. The 72% ALL_LEMMAS_MISSING rate will drop significantly once classical dictionaries are extracted. Prioritize: لسان العرب (29 MB), تاج العروس (40 MB), القاموس المحيط (5.8 MB).

2. **Normalization trade-offs**: Article stripping helps match الكتاب↔كتاب but may cause false matches in rare cases. Alef maqsura normalization (ى→ي) is aggressive but follows `qc_json.py` precedent.

3. **POS taxonomy mismatch**: AWN4 uses 4 POS values (n/v/a/r), the DB uses 8. Arabic participles (اسم الفاعل، اسم المفعول) and masdars blur the noun/verb/adj boundaries. The POS check catches real issues but also generates noise from this mismatch.

4. **Report size**: 66 MB for the full report is large. Consider a `--compact` mode that omits per-lemma details for ALL_LEMMAS_MISSING synsets.

---

## Recommendations

### Immediate Actions

1. **Extract and load classical dictionaries** into the SQLite DB to improve coverage from 24.9% toward the 58.9% target. Priority: Kitab al-Ayn (pending), Maqayis al-Lugha (pending), then Lisan al-Arab.

2. **Use DUPLICATE_SYNSETS output to prioritize Stage 4 review.** The 3,790 single-lemma polysemy groups (8,966 synsets) are the highest-value targets. Start with the worst offenders: عقد (18), رفع (15), رأس (13).

3. **Build an automated diacritics correction pass** using the 5,468 DIACRITICS_MISMATCH instances. Where the dictionary has a single unambiguous form, the correction can be applied automatically.

### Future Improvements

- **Reclassify ROOT_INCONSISTENCY** as informational metadata rather than an error flag.
- **Add masdar detection** to POS_MISMATCH to separate real errors from the masdar pattern.
- **Add a `--compact` mode** to reduce report size by omitting per-lemma details for ALL_LEMMAS_MISSING synsets.
- **Integrate with Stage 2 (root-family batching)** — use the root data from matched lemmas to group synsets for review.

## How to Run

```bash
# Default run
python experiments/prefilter_dict.py

# Custom output path
python experiments/prefilter_dict.py --output my_report.json

# Include clean (unflagged) synsets in output
python experiments/prefilter_dict.py --include-clean

# Custom paths
python experiments/prefilter_dict.py \
    --awn4-xml /path/to/awn4.xml \
    --dict-db /path/to/arabic_dict.db
```

## Query Examples

```python
import json

r = json.load(open('experiments/prefilter_report.json'))

# Find all synsets flagged for a specific issue
pos_issues = [sid for sid, d in r['synsets'].items() if 'POS_MISMATCH' in d['flags']]

# Find polysemy cases for a specific word
for dup in r['duplicate_synsets']:
    if 'عقد' in dup['lemma_set']:
        print(dup['synset_ids'])

# Get all diacritics mismatches
for sid, data in r['synsets'].items():
    for d in data['details']:
        if d['flag'] == 'DIACRITICS_MISMATCH':
            print(f"{sid}: {d['awn4_form']} vs {d['db_forms']}")
```
