## Motivation

Design a comprehensive quality review process for AWN4 synsets — both for human Arabic linguists and for LLM-based automated review. The goal was a broad review covering multiple quality axes, not focused on any single issue.

## What Was Built

### Human review framework (2026-02-09)

- **`ARABIC_REVIEW_INSTRUCTIONS.md`** — Review instructions in Arabic covering semantic validity, definition quality, cultural appropriateness
- **`REVIEW_PROCESS_GUIDE.md`** — Full standard operating procedure for linguist reviewers
- **`sample_for_review.csv`** — 100 randomly sampled synsets for human review
- **`generate_sample.py`** — Parses AWN4 XML, selects random synsets, writes CSV with review columns

### LLM review system (2026-02-09 to 2026-02-10)

- **`llm_linguist_prompt.md`** — 262-line system prompt covering 11+ review axes, using Almaany web data as evidence
- **`almaany_test_10.json`** / **`almaany_test_10_clean.json`** — Raw and cleaned Almaany web scrapes for 10 test synsets
- **`review_files/`** — 100 individual per-synset review documents generated by LLM

### Review axes covered by the LLM prompt

1. Semantic validity of Arabic definition
2. Definition completeness and naturalness
3. Example quality and cultural appropriateness
4. POS correctness
5. Lemma appropriateness
6. Synonym coverage
7. Hypernym chain correctness
8. Cultural relevance
9. Diacritization accuracy
10. Technical terminology usage
11. Overall quality score (1–5)

## Why It Was Superseded for Polysemy Work

The polysemy disambiguation task (Experiments 5–7) needed a fundamentally different approach:

| Factor | This Experiment | Polysemy Pipeline |
|---|---|---|
| Scope | 1 synset at a time | N synsets compared together |
| Output | ~2,000 tokens per synset | ~100 tokens per synset |
| Data source | Almaany web scraping | Authoritative dictionary DB |
| Task | Full quality review (11 axes) | Focused disambiguation only |
| Token cost at scale | ~25M output tokens | ~4M output tokens |

The single-synset review cannot discover polysemy issues because it never sees sibling synsets sharing the same lemma.

## Impact on Later Work

- **Arabic linguistic conventions:** The review tone, terminology, and cultural awareness criteria established here were reused in the polysemy review system prompt (`polysemy_reviews/polysemy_review.py`)
- **Data source lesson:** Almaany web scraping was fragile and unauthorized. The authoritative dictionary DB (المعجم الوسيط, المعجم الكبير) became the standard evidence source in all later experiments
- **Still relevant for RESEARCH_IDEAS #2:** The broader AWN4 translation quality audit (beyond polysemy) could use this framework — the 11-axis review covers issues the polysemy pipeline does not address
