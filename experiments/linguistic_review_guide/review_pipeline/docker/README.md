# Docker Support for Review Pipeline

Runs the 5-stage AWN4 review pipeline (`batch_runner.py` → `run_review.sh` → `claude -p`) inside a locked-down Docker container.

## Architecture

```
Host                              Container (claude-reviewer-v2)
─────────────────────────         ──────────────────────────────
prepared/          ──mount──►     /workspace/prepared  (ro)
spec/              ──mount──►     /workspace/spec      (ro)
review_instructions.md ─mount──► /workspace/review_instructions.md (ro)
db_reference.md    ──mount──►     /workspace/db_reference.md (ro)
run_review.sh      ──mount──►     /workspace/run_review.sh (ro)
batch_runner.py    ──mount──►     /workspace/batch_runner.py (ro)
batch_status.py    ──mount──►     /workspace/batch_status.py (ro)
arabic_dict.db     ──mount──►     /data/arabic_dict.db (ro)
output/reviews_pipeline_v2 ─►    /output (rw)
```

## Security

- **Egress firewall**: Default-deny iptables policy; only `api.anthropic.com`, `sentry.io`, `statsig.anthropic.com`, and `statsig.com` are whitelisted.
- **Read-only mounts**: All inputs are mounted `:ro`. Only `/output` is writable.
- **Credential hygiene**: Keychain credentials are injected via env var, written to a file, then the env var is cleared before `exec`.
- **Disposable container**: `--rm` flag ensures no state persists after the run.

## Prerequisites

1. Docker installed and running
2. `prepared/` directory generated by `extract_synset_info.py`
3. Arabic dictionary DB at the default path (or set `ARABIC_DICT_DB`)

## Usage

```bash
# All synsets, 4 workers (default)
./run_batch.sh

# Custom worker count
./run_batch.sh --workers 8

# Single synset
./run_batch.sh --workers 1 awn4-02592253-n

# Resume interrupted run
./run_batch.sh --resume --workers 4

# Batch file with adaptive concurrency
./run_batch.sh --batch /path/to/synsets.txt --workers 10 --adaptive

# Custom model
MODEL=haiku ./run_batch.sh --workers 10
```

## Environment Variables

| Variable | Default | Description |
|----------|---------|-------------|
| `GUIDE_DIR` | `~/Desktop/MLProjects/wn-project/.../linguistic_review_guide` | Parent guide directory |
| `PIPELINE_DIR` | `$GUIDE_DIR/review_pipeline` | Pipeline root |
| `PREPARED_DIR` | `$PIPELINE_DIR/prepared` | Prepared synset data |
| `OUTPUT_DIR` | `$GUIDE_DIR/output/reviews_pipeline_v2` | Review output directory |
| `ARABIC_DICT_DB` | `~/Desktop/.../arabic-dictionaries/db/arabic_dict.db` | Dictionary SQLite DB |
| `MODEL` | `sonnet` | Claude model to use |
| `WORKERS` | `4` | Default worker count |

## Files

| File | Purpose |
|------|---------|
| `Dockerfile` | Container image: Node.js 20, Claude Code, sqlite3, python3, firewall tools |
| `entrypoint.sh` | Init firewall → inject credentials → exec batch command |
| `init-firewall.sh` | iptables default-deny egress with domain whitelist |
| `run_batch.sh` | Host-side launcher: builds image, mounts volumes, runs container |
