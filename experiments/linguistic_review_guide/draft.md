# خوارزمية التحليل اللغوي

# Algorithm Linguistic Analysis

> هذه الخوارزمية تحوّل المراجع (سواء كان بشرياً أو ذكاءً اصطناعياً) إلى **ناقد لغوي**: يفحص اللمّات، يؤلف التعريفات، يثري الحقول، ويسجّل القرارات النهائية.

---

## الاصطلاحات — Conventions

```text
لكل X في Y نفّذ          FOR EACH X in Y DO
إذا ... فـ               IF ... THEN
وإلا إذا ... فـ          ELSE IF ... THEN
وإلا                     ELSE
نهاية                    END
⟵                        تعيين (assignment)
▸ أمر طبيعي              إجراء مؤسَّس على واجهة البرمجة (API-grounded action)
// تعليق                  ملاحظة توضيحية
┊                         مستوى التداخل (Scope Indentation)

```

## فضاء الأوامر — Action Space

```text

// ── أوامر اللمّات ──
▸ احذف ارتباط اللمّة بالمجموعة (سبب)     → remove_sense(sense_id)
▸ أكّد صلاحية اللمّة                      → set_confidence("sense", sense_id, 1.0)
▸ أضف لمّة جديدة إلى المجموعة             → create_entry() + add_sense()
▸ أضف تهجئة بديلة للمّة                   → add_form(entry_id, written_form)
▸ صحّح صيغة اللمّة                        → update_lemma(entry_id, new_form)
▸ اقبل التعبير المركب                     → set_metadata("sense", id, "mwe", true)
▸ اقبل اللفظ المعرّب                      → set_metadata("entry", id, "etymology", "loanword")
▸ اقبل كظرف                              → set_metadata("sense", id, "adverb_note", val)

// ── أوامر التعريفات ──
▸ عدّل نص التعريف                         → update_definition(synset_id, idx, text)
▸ أبقِ التعريف كما هو                     → (تحليلي)
▸ ألّف تعريفاً جديداً                     → add_definition(synset_id, text)

// ── أوامر العلاقات ──
▸ أضف علاقة دلالية                        → add_synset_relation() / add_sense_relation()
▸ صحّح العلاقة الدلالية                    → remove_synset_relation() + add_synset_relation()
▸ أقرّ صحة العلاقات                       → (تحليلي)
▸ اربط جمع التكسير بمفرده                 → add_sense_relation(plural, "derivation", singular)

// ── أوامر الإثراء والبيانات الوصفية ──
▸ سجّل ملاحظة دلالية                      → set_metadata("sense", id, "nuance", val)
▸ عيّن حقل إثراء                          → set_metadata("sense", id, key, val)
▸ حدّد الإطار التركيبي                     → set_metadata("sense", id, "syntactic_frame", val)
▸ أضف متلازمة لفظية                       → set_metadata("sense", id, "collocation", val)
▸ صحّح الجذر                              → set_metadata("entry", id, "root", val)

// ── أوامر الأمثلة ──
▸ أضف شاهداً استعمالياً                    → add_synset_example() / add_sense_example()

// ── أوامر بنيوية ──
▸ اقترح مجموعة ترادفية جديدة              → create_synset() + create_entry() + add_sense() + add_synset_relation()
▸ أشر إلى ضرورة فصل المجموعة              → create_synset() + move_sense() + add_synset_relation()
▸ أشر إلى خطأ نوع الكلمة                  → update_entry(id, pos=) / update_synset(id, pos=)
▸ أشر إلى ضرورة مراجعة التعريف             → (إشارة داخلية للخطوة ٣)
▸ أضف تعبيراً اصطلاحياً                   → create_entry() + add_sense()

// ── أوامر الملاءمة الثقافية ──
▸ أشر إلى فجوة معجمية                     → set_metadata("synset", id, "cultural_fit", "lexical_gap")
▸ أشر إلى مفهوم أجنبي لا مقابل له         → set_metadata("synset", id, "cultural_fit", "omission")
▸ أعد تصنيف الملاءمة الثقافية              → set_metadata("synset", id, "cultural_fit", val)

// ── أوامر التصعيد ──
▸ صعّد للمراجع البشري                     → set_metadata("synset", id, "escalation", reason) + set_confidence("synset", id, 0.0)
▸ ارفض المرشح                            → (تحليلي — المرشح لم يُضف أصلاً)

```

## المُدخلات — Inputs

```text
// ١. المجموعة الترادفية (Synset - مُدخل المرحلة الأولى)
مجموعة_ترادفية = {
    معرّف، لمّات، تعريف_عربي، تعريف_إنجليزي، نوع الكلمة (POS)، علاقات
}

// ٢. الملف البحثي (مُخرج المرحلة الأولى)
الملف_البحثي = {
    توثيق:           لمّة → {عدد_المعاجم، الفترات_الزمنية}
    تعريفات:         لمّة → [{مصدر، نص، مطابق، تشويش}]
    عائلة_الجذر:     {جذر، مشتقات، مرشحات}
    شواهد:           لمّة → [{نوع، نص، بالمعنى المقصود}]
    تطور_زمني:       لمّة → {تصنيف}
    مرشحات_المرادف:  [{كلمة، المصدر، ملاحظة}]
    arabterm:         [{مصطلح_عربي، مصطلح_أجنبي، المجال، تهجئة_بديلة}]
}

```

## الخوارزمية

```text
لكل مجموعة_ترادفية نفّذ

    // ══════════════════════════════════════════════
    // الخطوة ٠: استخلاص الأدلة المعجمية (Dictionary Evidence Extraction)
    // ══════════════════════════════════════════════

    لكل لمّة في مجموعة_ترادفية.لمّات نفّذ

        // استخلص من جميع النصوص المعجمية في الملف البحثي ما يتعلق بمعنى اللمّة
        // قارن الأدلة بتعريف المجموعة الترادفية (synset definition)
        // ملاحظة: التصنيفات الثلاثة (confirm/contradicts/expands) غير حصرية —
        // نص واحد قد ينتمي لأكثر من قائمة في آن واحد

        لكل نص_معجمي في الملف_البحثي.تعريفات(لمّة) نفّذ

            إذا نص_معجمي يؤكّد المعنى الدلالي للمّة بالنسبة لتعريف المجموعة فـ
                // تحليلي — تصنيف أدلة
                أضف_إلى(لمّة.confirm، نص_معجمي + المصدر)
            نهاية

            إذا نص_معجمي يناقض المعنى الدلالي أو يُضيّقه أو يُبعده عن تعريف المجموعة فـ
                // تحليلي — تصنيف أدلة
                أضف_إلى(لمّة.contradicts، نص_معجمي + المصدر + وجه_التناقض)
            نهاية

            إذا نص_معجمي يوسّع المعنى أو يضيف بعداً دلالياً غير موجود في تعريف المجموعة فـ
                // تحليلي — تصنيف أدلة
                أضف_إلى(لمّة.expands، نص_معجمي + المصدر + الإضافة_الدلالية)
            نهاية

        نهاية  // لكل نص معجمي

        // التحقق من وجود أدلة
        إذا لمّة.confirm فارغ و لمّة.contradicts فارغ و لمّة.expands فارغ فـ
            لمّة.evidence_status ⟵ "no_material_found"
            // اللمّة بلا سند معجمي — إشارة تحذيرية للخطوات اللاحقة
        نهاية

    نهاية  // لكل لمّة — استخلاص الأدلة


    // ══════════════════════════════════════════════
    // الخطوة ١: التحقق من اللمّات (Lemma Validation)
    // ══════════════════════════════════════════════

    لكل لمّة في مجموعة_ترادفية.لمّات نفّذ

        // ── قراءة أدلة الخطوة ٠ ──

        // حالة ١: لا سند معجمي — حكم اللغوي
        // (قرارات اللغوي تُوثَّق عبر «سجّل ملاحظة دلالية» — هي آلية التوثيق المعتمدة لضمان قابلية المراجعة)
        إذا لمّة.evidence_status = "no_material_found" فـ
            // لا أدلة معجمية — يرجع القرار للمعرفة اللغوية للمراجع
            // (في التشغيل الآلي: semantic_similarity(لمّة، تعريف_المجموعة) > عتبة)
            إذا اللغوي يرى أن اللمّة مرتبطة دلالياً بتعريف المجموعة (بناءً على معرفته) فـ
                ▸ سجّل ملاحظة دلالية(لمّة، "لا سند معجمي — مقبولة بحكم اللغوي")
                // أكمل الفحوصات أدناه
            وإلا
                ▸ احذف ارتباط اللمّة بالمجموعة(لمّة، سبب="لا سند معجمي ولا ارتباط دلالي بتعريف المجموعة")
                انتقل_للمّة_التالية
            نهاية
        نهاية

        // حالة ٢: يوجد تناقض — تشخيص مصدر التناقض
        إذا لمّة.contradicts غير_فارغ فـ
            إذا التناقض مصدره أن اللمّة تحمل معنى مختلفاً عن تعريف المجموعة فـ
                // اللمّة في المكان الخطأ — اختبار الإبدال سيؤكد
                ▸ سجّل ملاحظة دلالية(لمّة، "تناقض: المعنى المعجمي يختلف عن تعريف المجموعة")
            وإلا إذا التناقض مصدره أن تعريف المجموعة ضيّق أو خاطئ فـ
                // المشكلة في التعريف لا في اللمّة — إشارة للخطوة ٣
                ▸ سجّل ملاحظة دلالية(لمّة، "تناقض: تعريف المجموعة يحتاج مراجعة")
                ▸ أشر إلى ضرورة مراجعة التعريف()
            وإلا إذا التناقض مصدره تعدد معاني اللمّة (Polysemy) فـ
                // اللمّة لها معنى مطابق ومعنى مختلف — تحتاج فصلاً
                ▸ أشر إلى ضرورة فصل المجموعة()
                ▸ سجّل ملاحظة دلالية(لمّة، "تناقض: تعدد معانٍ — تحقق من المعنى المقصود")
            نهاية
        نهاية

        // حالة ٣: يوجد توسيع — تقييم طبيعة التوسيع
        إذا لمّة.expands غير_فارغ فـ
            إذا التوسيع يمثل معنى مستقلاً لا يندرج تحت تعريف المجموعة فـ
                ▸ أشر إلى ضرورة فصل المجموعة()
                ▸ سجّل ملاحظة دلالية(لمّة، "توسيع: معنى إضافي قد يستحق مجموعة ترادفية مستقلة")
            وإلا
                // التوسيع فارق دقيق يُغني المجموعة
                ▸ سجّل ملاحظة دلالية(لمّة، "توسيع: بُعد دلالي إضافي — " + الإضافة_الدلالية)
            نهاية
        نهاية

        // حالة ٤: تأكيد فقط — مسار سريع
        // (لمّة.confirm غير فارغ ولا تناقض ولا توسيع — الأدلة تدعم الانتماء)

        // ── الفحوصات الأصلية (تستفيد الآن من الأدلة أعلاه) ──

        // أ٠. التعابير متعددة الكلمات (Multi-Word Expressions)
        // بعض المفاهيم مركبة بطبيعتها (مثل: احتباس حراري، ذكاء اصطناعي)
        // تُعامَل كلمّات أساسية لا كحالات شاذة
        إذا لمّة تعبير_مركب (MWE) فـ
            إذا التركيب اصطلاحي_مستقر ويحمل معنى وحدوياً لا تركيبياً فـ
                ▸ اقبل التعبير المركب(لمّة)
                // يُمرَّر لاختبار الإبدال أدناه كوحدة واحدة
            وإلا
                // تركيب عرضي — ليس وحدة معجمية
                ▸ احذف ارتباط اللمّة بالمجموعة(لمّة، سبب="تركيب غير اصطلاحي — ليس وحدة معجمية")
                انتقل_للمّة_التالية
            نهاية
        نهاية

        // أ. اختبار الإبدال (Substitution Test) ← انظر الإجراء الفرعي اختبار_الإبدال()
        إذا اختبار_الإبدال(لمّة، أخوات_المجموعة) = نجاح فـ
            مرادفة ⟵ صحيح
        وإلا
            ▸ احذف ارتباط اللمّة بالمجموعة(لمّة، سبب="فشل اختبار الإبدال")
            انتقل_للمّة_التالية
        نهاية

        // ب. مبدأ منع الترادف التام (No Absolute Synonymy)
        ▸ سجّل ملاحظة دلالية(لمّة، الفارق_الذي_يميزها_عن_أخواتها)   // إلزامي دائماً

        // ج. اللفظ المختص أولى
        // (اللفظ الأخصّ يجتاز اختبار الإبدال ضمنياً — الأخصية تستلزم الإبدال في سياق المفهوم المحدد)
        إذا يوجد_لفظ_أخصّ_من(لمّة) للمفهوم فـ
            ▸ احذف ارتباط اللمّة بالمجموعة(لمّة، سبب="يوجد لفظ أخصّ")
            ▸ أضف لمّة جديدة إلى المجموعة(اللفظ_الأخصّ)
        نهاية

        // د. كشف الترجمة الحرفية والمعرّب (Calques & Loanwords)
        إذا لمّة تركيب_أعجمي_البنية (مثل: مطر ثقيل بدل غزير) فـ
            ▸ احذف ارتباط اللمّة بالمجموعة(لمّة، سبب="ترجمة حرفية أعجمية البنية")
            إذا المقابل_العربي_الأصيل غير_موجود في لمّات_المجموعة فـ
                ▸ أضف لمّة جديدة إلى المجموعة(المقابل_العربي_الأصيل)
            نهاية
            انتقل_للمّة_التالية
        وإلا إذا لمّة لفظ_دخيل_أو_معرّب ومُقرّ مجمعياً أو شائع علمياً فـ
            ▸ اقبل اللفظ المعرّب(لمّة)
            ▸ عيّن حقل إثراء(لمّة، eloquence="neologism/loanword")
        نهاية

        // ز. القرار النهائي للمة (مُعزَّز بأدلة الخطوة ٠)
        //
        // الحالات الممكنة عند الوصول هنا:
        //   أ) confirm فقط (لا تناقض ولا توسيع)
        //   ب) confirm + contradicts (أدلة متضاربة)
        //   ج) confirm + expands أو expands فقط (معنى أوسع)
        //   د) no_material_found لكن اللغوي وافق (confirm و contradicts فارغان)
        //   هـ) contradicts فقط (وصلت رغم التناقض — نجحت في الإبدال)

        // ── أولاً: فحص الانزياح الزمني (ينطبق على كل حالة فيها أدلة) ──
        إذا لمّة.confirm غير_فارغ و يوجد انزياح_زمني (Semantic shift) فـ
            ▸ أكّد صلاحية اللمّة(لمّة)
            ▸ سجّل ملاحظة دلالية(لمّة، "period restriction")
            ▸ عيّن حقل إثراء(لمّة، usage_note="المعنى تطوّر عبر العصور")
            انتقل_للمّة_التالية
        نهاية

        // ── ثانياً: فحص الكلمة المولّدة (ينطبق على كل الحالات) ──
        إذا الكلمة مولّدة بلا_أصل_كلاسيكي فـ
            ▸ أكّد صلاحية اللمّة(لمّة)
            ▸ عيّن حقل إثراء(لمّة، usage="modern")
            انتقل_للمّة_التالية
        نهاية

        // ── ثالثاً: القرار حسب حالة الأدلة ──

        // (أ) أدلة مؤكدة بلا تناقض
        إذا لمّة.confirm غير_فارغ و لمّة.contradicts فارغ فـ
            ▸ أكّد صلاحية اللمّة(لمّة)

        // (ب) أدلة متضاربة — يعتمد على وزن الأدلة
        وإلا إذا لمّة.confirm غير_فارغ و لمّة.contradicts غير_فارغ فـ
            إذا أدلة_التأكيد أقوى (أكثر مصادر أو أحدث) فـ
                ▸ أكّد صلاحية اللمّة(لمّة)
                ▸ سجّل ملاحظة دلالية(لمّة، "تأكيد مع تحفظ — بعض المصادر تخالف")
            وإلا
                ▸ صعّد للمراجع البشري()   // تعارض حقيقي يحتاج مراجعاً بشرياً
            نهاية

        // (ج) توسيع فقط بلا تأكيد صريح — الأدلة توسّع لا تؤكد
        وإلا إذا لمّة.expands غير_فارغ و لمّة.confirm فارغ و لمّة.contradicts فارغ فـ
            // المعاجم تذكر اللمّة بمعنى أوسع من تعريف المجموعة
            // اللمّة صالحة لكن تعريف المجموعة قد يحتاج توسيعاً
            ▸ أكّد صلاحية اللمّة(لمّة)
            ▸ سجّل ملاحظة دلالية(لمّة، "الأدلة المعجمية توسّع المعنى — تحقق من نطاق التعريف")

        // (د) لا أدلة معجمية لكن اللغوي وافق في حالة ١
        وإلا إذا لمّة.evidence_status = "no_material_found" فـ
            // وصلت هنا لأن اللغوي رأى ارتباطاً دلالياً ونجحت في الإبدال
            ▸ أكّد صلاحية اللمّة(لمّة)
            ▸ سجّل ملاحظة دلالية(لمّة، "مقبولة بحكم اللغوي — بلا سند معجمي مباشر")

        // (هـ) تناقض فقط بلا تأكيد — وصلت رغم ذلك (نجحت في الإبدال)
        وإلا إذا لمّة.contradicts غير_فارغ و لمّة.confirm فارغ فـ
            ▸ صعّد للمراجع البشري()   // الإبدال نجح لكن المعاجم تخالف — يحتاج حسماً بشرياً

        // لم تنطبق أي حالة — رفض
        وإلا
            ▸ احذف ارتباط اللمّة بالمجموعة(لمّة، سبب="لم تنطبق أي حالة تأكيد")
        نهاية

    نهاية  // نهاية التحقق من اللمّات


    // ══════════════════════════════════════════════
    // الخطوة ٢: اكتشاف لمّات مفقودة (Missing Lemmas)
    // ══════════════════════════════════════════════

    // ── §2.1 توليد مرشحات بالاشتقاق العكسي بالتضاد (Reverse Antonymy Generation) ──
    // العربية تلجأ لأسلوب "غير + صفة" عند غياب المقابل المباشر في ذهن المترجم.
    // هذه الآلية تعكس العملية: تستخرج الكلمة المثبتة، تبحث عن أضدادها، وتولّد مرشحات.
    لكل لمّة في اللمّات_المؤكدة نفّذ
        إذا اللمّة تبدأ بـ (غير | عدم | لا | بلا) فـ
            الكلمة_المثبتة ⟵ احذف_أداة_النفي(اللمّة)   // "غير حاسم" → "حاسم"
            أضداد_المثبت ⟵ ابحث_في_الملف_البحثي_عن_أضداد(الكلمة_المثبتة)

            لكل ضد في أضداد_المثبت نفّذ
                // مثال: ضد "حاسم" → "ظني"، "معلق"، "ملتبس"
                إذا ضد غير_موجود_في الملف_البحثي.مرشحات_المرادف فـ
                    أضف_إلى(الملف_البحثي.مرشحات_المرادف، {
                        كلمة: ضد،
                        المصدر: "توليد آلي بالتضاد"،
                        ملاحظة: "مستخرج من ضد الكلمة المثبتة: " + الكلمة_المثبتة
                    })
                نهاية
            نهاية
        نهاية
    نهاية

    // ── §2.2 استخلاص مرشحات من التعريف (Definition-to-Lemma Mapping) ──
    // اللمّة الأفضل قد تكون مختبئة داخل نص التعريف نفسه.
    // مثال: "ما لا يقطع الشك باليقين" → جذر "شك" → مشتقات: مَشْكُوك، شاكّ
    كلمات_مفتاحية ⟵ استخرج_الكلمات_الدلالية(تعريف_AWN + التعريفات_المعجمية)
    لكل كلمة في كلمات_مفتاحية نفّذ
        مشتقات ⟵ استخرج_المشتقات(كلمة)   // اسم فاعل، اسم مفعول، صفة مشبهة، صيغة مبالغة
        لكل مشتق في مشتقات نفّذ
            إذا مشتق غير_موجود_في اللمّات_المؤكدة و غير_موجود_في مرشحات_المرادف فـ
                إذا تقييم_التشابه_الدلالي(مشتق، تعريف_المجموعة) > عتبة_مرتفعة فـ
                    أضف_إلى(الملف_البحثي.مرشحات_المرادف، {
                        كلمة: مشتق،
                        المصدر: "اشتقاق من التعريف"،
                        ملاحظة: "مشتق من الكلمة المفتاحية: " + كلمة
                    })
                نهاية
            نهاية
        نهاية
    نهاية

    // ── §2.3 تقييم المرشحات ──
    لكل مرشح في الملف_البحثي.مرشحات_المرادف نفّذ

        // ── استخلاص أدلة المرشح (نفس منطق الخطوة ٠ — يُنتج بيانات أدلة مكتملة ومكافئة) ──
        لكل نص_معجمي في الملف_البحثي.تعريفات(مرشح) نفّذ
            إذا نص_معجمي يؤكّد المعنى الدلالي للمرشح بالنسبة لتعريف المجموعة فـ
                // تحليلي — تصنيف أدلة
                أضف_إلى(مرشح.confirm، نص_معجمي + المصدر)
            نهاية
            إذا نص_معجمي يناقض المعنى فـ
                // تحليلي — تصنيف أدلة
                أضف_إلى(مرشح.contradicts، نص_معجمي + المصدر)
            نهاية
            إذا نص_معجمي يوسّع المعنى فـ
                // تحليلي — تصنيف أدلة
                أضف_إلى(مرشح.expands، نص_معجمي + المصدر)
            نهاية
        نهاية

        // ── بوابة الأدلة: فلترة مبكرة ──

        // لا سند معجمي — حكم اللغوي
        // (في التشغيل الآلي: semantic_similarity(مرشح، تعريف_المجموعة) < عتبة)
        إذا مرشح.confirm فارغ و مرشح.contradicts فارغ و مرشح.expands فارغ فـ
            إذا اللغوي لا يرى ارتباطاً دلالياً بتعريف المجموعة فـ
                ▸ ارفض المرشح(مرشح)
                انتقل_للمرشح_التالي
            نهاية
        نهاية

        // تناقض فقط بلا تأكيد — لكن تحقق: هل هو أخصّ دلالياً؟
        إذا مرشح.confirm فارغ و مرشح.contradicts غير_فارغ فـ
            إذا التناقض مصدره أن المرشح أضيق دلالياً من تعريف المجموعة فـ
                // المجموعة المقترحة تُسجَّل كمُخرَج وتُعالج في دورة مراجعة لاحقة
                ▸ اقترح مجموعة ترادفية جديدة(مرشح)
                ▸ أضف علاقة دلالية(المجموعة_الجديدة، "hyponym"، مجموعة_ترادفية)
                ▸ سجّل ملاحظة دلالية(مرشح، "أخصّ دلالياً — اكتُشف عبر أدلة التناقض")
            وإلا
                ▸ ارفض المرشح(مرشح)
            نهاية
            انتقل_للمرشح_التالي
        نهاية

        // ── اختبار الترادف المتقاطع (Cross-referencing) ──
        تعريف_أ_يذكر_ب ⟵ (تعريف المرشح يذكر لمّات المجموعة)
        تعريف_ب_يذكر_أ ⟵ (تعريف لمّة المجموعة يذكر المرشح)
        ترادف_محتمل ⟵ تعريف_أ_يذكر_ب أو تعريف_ب_يذكر_أ

        // ── اختبار الإبدال (مشروط بالترادف المتقاطع أو أدلة التأكيد) ──
        إذا ترادف_محتمل أو مرشح.confirm غير_فارغ فـ

            إذا المرشح ينجح في اختبار_الإبدال مع اللمّات_المؤكدة فـ
                ▸ أضف لمّة جديدة إلى المجموعة(مرشح)
                // المرشح المضاف يحتاج فحوصات الخطوة ١ الأساسية
                ▸ سجّل ملاحظة دلالية(مرشح، الفارق_الذي_يميزه_عن_أخواته)   // إلزامي
                إذا مرشح.expands غير_فارغ فـ
                    ▸ سجّل ملاحظة دلالية(مرشح، "بُعد دلالي إضافي — " + الإضافة)
                نهاية

                // ── مبدأ أولوية اللفظة المفردة (Lexicalization Preference) ──
                // اللفظة المفردة تُفضَّل على التركيب الوصفي إذا أدّت نفس المعنى
                إذا المرشح كلمة_مفردة فـ
                    لكل لمّة_مؤكدة في اللمّات_المؤكدة نفّذ
                        إذا لمّة_مؤكدة تعبير_مركب يبدأ بـ (غير | عدم | لا | بلا) فـ
                            ▸ سجّل ملاحظة دلالية(مرشح، "أفضلية معجمية: لفظ مفرد يغني عن التركيب الوصفي [" + لمّة_مؤكدة + "]")
                            ▸ سجّل ملاحظة دلالية(لمّة_مؤكدة، "تركيب وصفي — الكلمة المفردة [" + مرشح + "] أدق معجمياً")
                        نهاية
                    نهاية
                نهاية

            وإلا إذا المرشح تهجئة_بديلة لِلمّة_موجودة فـ
                // التهجئة البديلة تظهر في نفس المداخل المعجمية
                ▸ أضف تهجئة بديلة للمّة(اللمّة_الموجودة، المرشح)

            وإلا إذا المرشح أخصّ_دلالياً (Hyponym) فـ
                ▸ اقترح مجموعة ترادفية جديدة(مرشح)
                ▸ أضف علاقة دلالية(المجموعة_الجديدة، "hyponym"، مجموعة_ترادفية)

            وإلا
                ▸ ارفض المرشح(مرشح)
            نهاية

        وإلا
            // لا ترادف متقاطع ولا أدلة تأكيد — لا يستحق اختبار الإبدال
            ▸ ارفض المرشح(مرشح)
        نهاية

    نهاية  // نهاية فحص المرشحات


    // ══════════════════════════════════════════════
    // الخطوة ٣: تدقيق وتأليف التعريف (Definition Processing)
    // ══════════════════════════════════════════════

    // ── استهلاك إشارة «أشر إلى ضرورة مراجعة التعريف» من الخطوة ١ ──
    إذا إشارة_مراجعة_التعريف مرفوعة فـ
        // أدلة الخطوة ٠ أظهرت أن التعريف ضيّق أو خاطئ — المراجعة إلزامية
        ▸ عدّل نص التعريف()
    وإلا إذا تعريف_AWN يطابق المعاجم فـ
        ▸ أبقِ التعريف كما هو()
    وإلا إذا التعريف_الكلاسيكي أوسع فـ
        ▸ سجّل ملاحظة دلالية("scope"، الفرق)
    وإلا إذا تعريف_AWN أدق_علمياً فـ
        ▸ أبقِ التعريف كما هو()   // إعطاء الأولوية للدقة العلمية
    وإلا
        ▸ عدّل نص التعريف()
    نهاية

    // تأليف التعريفات (فقط إذا كان التعريف يحتاج مراجعة أو تأليفاً)
    إذا عدّل_نص_التعريف تم_استدعاؤه أو لا_يوجد_تعريف_عربي فـ
        ▸ ألّف تعريفاً جديداً(نوع="مصطلحي")      // ← انظر الإجراء الفرعي أدناه
        إذا المفهوم بسيط_محسوس أو مجرد أو فعل فـ
            ▸ ألّف تعريفاً جديداً(نوع="لغوي")      // ← انظر الإجراء الفرعي أدناه
        نهاية
        إذا المفهوم حيوان أو نبات أو أداة أو مفهوم_ثقافي_معقد فـ
            ▸ ألّف تعريفاً جديداً(نوع="موسوعي")
        نهاية

        // فحص الجودة
        لكل تعريف في التعريفات_المؤلَّفة نفّذ
            ▸ تحقق_جودة(تعريف)                 // ← انظر الإجراء الفرعي أدناه
        نهاية
    نهاية


    // ══════════════════════════════════════════════
    // الخطوة ٤: فحص العلاقات (Relations Check)
    // ══════════════════════════════════════════════

    // ── اختبار التعميم (Hypernymy) ──
    // البحث في الشجرة الدلالية محدود بعمق ٣ مستويات لتقييد نطاق المقارنة
    إذا "X هو فعلاً نوع من Y" فـ
        ▸ أقرّ صحة العلاقات()
    وإلا إذا "X نوع من Y تقنياً لكن يوجد أعم أقرب" فـ
        ▸ صحّح العلاقة الدلالية(اقتراح = الأعم_الأقرب)
    وإلا
        ▸ صحّح العلاقة الدلالية(سبب = خطأ_في_التسلسل)
    نهاية

    // ── اختبار التضاد (Antonymy) ──
    // التضاد علاقة محورية خاصة في الأفعال والصفات
    لكل لمّة في اللمّات_المؤكدة نفّذ
        إذا يوجد ضد_مباشر للمّة في الملف_البحثي أو الشبكة الدلالية فـ
            إذا علاقة_التضاد مسجّلة_بالفعل في علاقات_المجموعة فـ
                ▸ أقرّ صحة العلاقات()
            وإلا
                ▸ أضف علاقة دلالية(لمّة، "antonym"، الضد)
            نهاية
        نهاية
        // التضاد يساعد أيضاً في التحقق: إذا ضد اللمّة = مرادف آخر في نفس المجموعة
        // فهذا دليل على خلط دلالي
        إذا ضد_اللمّة موجود_في نفس_المجموعة فـ
            ▸ أشر إلى ضرورة فصل المجموعة()
            ▸ سجّل ملاحظة دلالية(لمّة، "تضاد داخلي: اللمّة وضدها في نفس المجموعة")
        نهاية
    نهاية

    // ── فحوصات إضافية تخص الأفعال ──
    إذا لمّة.نوع = فعل فـ
        إذا الفعل يتعدى_بحرف فـ
            ▸ حدّد الإطار التركيبي(لمّة، "متعدٍ بـ " + الحرف)
        نهاية
        إذا خلط بين مصدر واسم_فاعل في نفس المجموعة فـ
            ▸ أشر إلى ضرورة فصل المجموعة()
        نهاية
    نهاية

    إذا الكلمة تتطلب فاعلاً عاقلاً/حيّاً/جماداً فـ
        ▸ سجّل ملاحظة دلالية(لمّة، القيد_الدلالي)
    نهاية


    // ══════════════════════════════════════════════
    // الخطوة ٥: الإثراء والملاءمة الثقافية (Enrichment & Culture)
    // ══════════════════════════════════════════════

    لكل لمّة في اللمّات_المؤكدة_والمضافة نفّذ

        // ── استهلاك بيانات التوسيع من الخطوة ٠ ──
        إذا لمّة.expands غير_فارغ فـ
            // الأبعاد الدلالية المستخلصة مسبقاً تُستخدم لملء حقول الإثراء
            لكل توسيع في لمّة.expands نفّذ
                إذا توسيع يتعلق بالاستعمال (archaic/modern) فـ ▸ عيّن حقل إثراء(لمّة، usage=القيمة_المستخلصة)
                إذا توسيع يتعلق بالدلالة (positive/negative) فـ ▸ عيّن حقل إثراء(لمّة، connotation=القيمة_المستخلصة)
                إذا توسيع يتعلق بالمجاز فـ ▸ عيّن حقل إثراء(لمّة، literal_figurative="figurative")
                إذا توسيع يتعلق بقيد تركيبي فـ ▸ حدّد الإطار التركيبي(لمّة، الإطار_المستخلص)
            نهاية
        نهاية

        // ── الإثراء (§2.6) ──
        ▸ صحّح الجذر(لمّة) إذا لزم
        ▸ عيّن حقل إثراء(لمّة، usage=...)                // archaic / modern / common
        ▸ عيّن حقل إثراء(لمّة، eloquence=...)            // eloquent / neologism / colloquial
        ▸ عيّن حقل إثراء(لمّة، connotation=...)          // positive / negative / reverential / pejorative / neutral
        ▸ عيّن حقل إثراء(لمّة، literal_figurative=...)   // literal / figurative

        إذا لمّة.literal_figurative = figurative فـ
            ▸ عيّن حقل إثراء(لمّة، figurative_relation=...)
        نهاية

        // استخلاص من النص المعجمي للملء الآلي
        لكل نص_معجمي في الملف_البحثي.تعريفات(لمّة) نفّذ
            إذا نص يحتوي "من المجاز" أو "يُستعار لـ" فـ ▸ عيّن حقل إثراء(لمّة، literal_figurative="figurative"، figurative_relation=...)
            إذا نص يحتوي نمط "فَعَلَ كذا بكذا" فـ ▸ حدّد الإطار التركيبي(لمّة، الإطار)
            إذا نص يحتوي "مولَّد" أو "محدث" فـ ▸ عيّن حقل إثراء(لمّة، usage="modern")
            إذا نص يحتوي "عامي" أو "مبتذل" فـ ▸ عيّن حقل إثراء(لمّة، eloquence="colloquial")
            إذا نص يحتوي "لا يُقال إلا لـ" فـ ▸ سجّل ملاحظة دلالية(لمّة، القيد)
        نهاية

        // ── حسم تعارض قيم الإثراء ──
        // مصادر مختلفة قد تُعطي قيماً متضاربة (مثلاً: "archaic" في معجم و"modern" في آخر)
        // العربية تمتد عبر ١٤ قرناً — كلمة واحدة قد تحمل تصنيفين بحق
        لكل حقل في [usage، eloquence، connotation] نفّذ
            إذا وُجدت قيم متعارضة لنفس الحقل من مصادر مختلفة فـ
                ▸ عيّن حقل إثراء(لمّة، حقل=[القيمة_١، القيمة_٢])   // السماح بقيم متعددة
                ▸ سجّل ملاحظة دلالية(لمّة، "تعارض في " + حقل + ": " + المصادر_والقيم)
            نهاية
        نهاية

        ▸ عيّن حقل إثراء(لمّة، source=المعجم_الداعم)

        // ── المتلازمات اللفظية (Collocations) ──
        // امسح النصوص المعجمية والشواهد بحثاً عن تراكيب متكررة مع اللمّة
        // أنواع المتلازمات:
        //   verb_object   — فعل + مفعول: "ألقى خطبة"، "أدّى صلاة"
        //   adj_noun      — صفة + اسم:  "حكم قاطع"، "خطأ فادح"
        //   noun_noun     — مضاف + مضاف إليه: "دار العلم"، "بيت القصيد"
        //   verb_prep     — فعل + حرف جر: "رغب في"، "عدل عن"
        //   adv_verb      — ظرف/حال + فعل: "سار سيراً حثيثاً"
        لكل نص_معجمي_أو_شاهد في الملف_البحثي نفّذ
            إذا يوجد تركيب متكرر مع اللمّة وليس تركيباً حراً فـ
                حدّد نوع_المتلازمة   // verb_object | adj_noun | noun_noun | verb_prep | adv_verb
                حدّد المصدر          // المعجم أو الشاهد الذي ورد فيه
                ▸ أضف متلازمة لفظية(لمّة، المتلازم، النوع، المصدر)
            نهاية
        نهاية

        // ── التحقق الصرفي (§2.7) ──
        إذا لمّة جمع_تكسير مدرج_كلمة_مستقلة فـ ▸ اربط جمع التكسير بمفرده(لمّة، المفرد)
        إذا الجذر_المُستنتج ≠ الشواهد فـ ▸ صحّح الجذر(لمّة، الجذر_الصحيح)

        // ── إرشادات حسب نوع الكلمة (POS) (§2.8) ──
        إذا لمّة.نوع = اسم فـ
            إذا خلط بين مَأْل ≠ مال فـ ▸ صحّح صيغة اللمّة(لمّة، الصيغة_الصحيحة)
            إذا خلط مصدر باسم_ذات فـ ▸ أشر إلى خطأ نوع الكلمة()
        وإلا إذا لمّة.نوع = فعل فـ
            ▸ حدّد الإطار التركيبي(لمّة، ...)   // لازم / متعدٍ بنفسه / متعدٍ بـ حرف
            إذا حرف_الجر يغيّر المعنى فـ ▸ سجّل ملاحظة دلالية(لمّة، الحرف + المعنى)
        وإلا إذا لمّة.نوع = صفة فـ
            إذا تركيب "صفة + جداً" فـ ▸ صحّح صيغة اللمّة(لمّة، صيغة_المبالغة)
        وإلا إذا لمّة.نوع = ظرف فـ
            إذا اللمّة جار_ومجرور أو حال تؤدي معنى الظرف فـ
                ▸ اقبل كظرف(لمّة) // للحفاظ على توافق WordNet العالمي
            وإلا
                ▸ أشر إلى خطأ نوع الكلمة()
            نهاية
        نهاية

    نهاية  // لكل لمّة — الإثراء

    // ── الملاءمة الثقافية (Cultural Fit) ──
    إذا المفهوم لا_مقابل_مفرد في العربية فـ
        إذا يمكن التعبير بتعبير_اصطلاحي فـ
            ▸ أضف تعبيراً اصطلاحياً()
            ▸ عيّن حقل إثراء(المجموعة، cultural_fit.lexical_gap_type="phraset")
        وإلا
            ▸ أشر إلى فجوة معجمية()
```

### تحقق_جودة(تعريف)

```text
دالة تحقق_جودة(تعريف):
    // شروط الجودة الخمسة
    إذا التعريف غامض فـ ▸ أعد_الصياغة(clarity)
    إذا فيه كلمات زائدة فـ ▸ احذف_الزائد(conciseness)
    إذا أوسع أو أضيق من المفهوم فـ ▸ اضبط_النطاق(equivalence)
    إذا يعرّف بالنفي فـ ▸ أعد_صياغة_إيجابية(positive)
    إذا يحتوي لفظ المعرَّف نفسه فـ ▸ أزل_الدور(no_tautology)

    // العيوب الستة
    إذا الجنس يكرّر ما فيه ضمنياً فـ ▸ احذف_الحشو()
    إذا الجنس بعيد جداً فـ ▸ استخدم_الجنس_القريب()
    إذا التعريف أغرب من المعرَّف فـ ▸ بسّط()
    إذا A يُعرَّف بـ B و B بـ A فـ ▸ عرّف_بخصائص_مستقلة()
    إذا إحالات متسلسلة فـ ▸ عرّف_مباشرة()
    إذا لفظ مشترك بلا تمييز فـ ▸ أضف_قيداً_مميزاً()
نهاية_الدالة

```

### اختبار_الإبدال(لمّة، أخوات)

```text
دالة اختبار_الإبدال(لمّة، أخوات):
    // المبدأ: اللمّة تصلح مرادفاً إذا أمكن إبدالها بأخواتها في سياقات طبيعية
    // دون تغيير جوهري في المعنى المقصود.

    // ١. نوع السياقات: نثر فصيح معاصر (لا شعر ولا نصوص متخصصة حصراً)
    // ٢. طريقة الاختبار: ضع اللمّة في جملة طبيعية، ثم أبدلها بكل أخت —
    //    هل يبقى المعنى الجوهري محفوظاً؟
    // ٣. معيار النجاح: الإبدال يحفظ المعنى الجوهري وإن اختلفت الظلال الدلالية.
    //    الفوارق في المستوى (فصيح/محايد) أو الإيحاء (إيجابي/سلبي) لا تُفشل الاختبار
    //    بل تُوثَّق في «سجّل ملاحظة دلالية».
    // ٤. معيار الفشل: الإبدال يُغيّر المعنى المقصود أو يُنتج جملة غير مقبولة لغوياً.
    // ٥. التسامح النحوي: الفشل النحوي البحت (حرف جر مختلف، بنية إضافة/مفعولية)
    //    لا يُفشل الاختبار إذا كان المعنى الجوهري محفوظاً بعد تكييف السياق.
    //    مثال: "غير واضح" → "مبهم" — حرف الجر يتغير لكن المعنى واحد.

    لكل أخت في أخوات نفّذ
        محاولة ⟵ إبدال(لمّة، أخت)

        إذا محاولة.يحفظ_المعنى فـ
            استمر

        وإلا إذا محاولة.فشل_نحوي و محاولة.المعنى_محفوظ فـ
            // الكلمة صحيحة دلالياً لكن السياق النحوي انكسر
            // (مثل: تغيير حرف الجر، أو تحويل المضاف إليه لمفعول به)
            سياق_معدل ⟵ كيّف_السياق_النحوي(الجملة، لمّة)
            إذا السياق_المعدل يحفظ المعنى الجوهري فـ
                ▸ حدّد الإطار التركيبي(لمّة، الإطار_الجديد)
                استمر   // عُدّ الاختبار ناجحاً
            وإلا
                أعد فشل
            نهاية

        وإلا   // فشل دلالي — المعنى تغيّر
            أعد فشل
        نهاية
    نهاية
    أعد نجاح
نهاية_الدالة

```

## فهرس الأوامر (▸) → واجهة البرمجة

### ١. أوامر التعديل (Modification)

| الأمر | الوصف | API |
| --- | --- | --- |
| `▸ عدّل نص التعريف` | التعريف ركيك أو حرفي أو خاطئ البنية | `update_definition(synset_id, idx, text)` |
| `▸ صحّح صيغة اللمّة` | خطأ إملائي أو صرفي أو متجانسات تحتاج تشكيلاً | `update_lemma(entry_id, new_form)` |
| `▸ صحّح الجذر` | الجذر المستنتج من المرحلة 1 خاطئ | `set_metadata("entry", id, "root", val)` |
| `▸ اربط جمع التكسير بمفرده` | ربط جمع تكسير (مدرج ككلمة مستقلة) بمفرده | `add_sense_relation(plural, "derivation", singular)` |
| `▸ صحّح العلاقة الدلالية` | تصحيح علاقة hypernym/hyponym الخاطئة | `remove_synset_relation()` + `add_synset_relation()` |
| `▸ أعد تصنيف الملاءمة الثقافية` | تصنيف المحاذاة الثقافية كان خاطئاً | `set_metadata("synset", id, "cultural_fit", val)` |

### ٢. أوامر الإضافة (Addition)

| الأمر | الوصف | API |
| --- | --- | --- |
| `▸ أضف لمّة جديدة إلى المجموعة` | مرادف صالح غير موجود في المجموعة | `create_entry()` + `add_sense(entry_id, synset_id)` |
| `▸ أضف تهجئة بديلة للمّة` | تهجئة بديلة للمّة موجودة | `add_form(entry_id, written_form)` |
| `▸ اقبل التعبير المركب` | قبول تعبير مركب (MWE) كوحدة معجمية أساسية | `set_metadata("sense", id, "mwe", true)` |
| `▸ أضف علاقة دلالية` | إضافة علاقة (antonym / hyponym) بين مجموعتين أو لمّتين | `add_synset_relation()` / `add_sense_relation()` |
| `▸ اقبل اللفظ المعرّب` | قبول كلمة معرّبة أو دخيلة متداولة | `set_metadata("entry", id, "etymology", "loanword")` |
| `▸ اقبل كظرف` | قبول تركيب نحوي كـ "ظرف" للتوافق العالمي | `set_metadata("sense", id, "adverb_note", val)` |
| `▸ أضف شاهداً استعمالياً` | إضافة شاهد (عند غياب شواهد حقيقية) | `add_synset_example()` / `add_sense_example()` |
| `▸ ألّف تعريفاً جديداً` | تأليف تعريف (مصطلحي / لغوي / موسوعي) | `add_definition(synset_id, text)` |
| `▸ سجّل ملاحظة دلالية` | **إلزامي** — تحديد الفارق الدقيق لكل لمّة | `set_metadata("sense", id, "nuance", val)` |
| `▸ أضف متلازمة لفظية` | إضافة تلازم لفظي مع نوعه ومصدره (verb_object / adj_noun / noun_noun / verb_prep / adv_verb) | `set_metadata("sense", id, "collocation", val)` |
| `▸ حدّد الإطار التركيبي` | للأفعال: تحديد حرف الجر الذي يضبط المعنى | `set_metadata("sense", id, "syntactic_frame", val)` |
| `▸ عيّن حقل إثراء` | تعبئة حقول: usage / eloquence / connotation | `set_metadata("sense", id, key, val)` |
| `▸ أضف تعبيراً اصطلاحياً` | فجوة معجمية تُسدّ بتعبير اصطلاحي | `create_entry()` + `add_sense()` |

### ٣. أوامر الحذف (Removal)

| الأمر | الوصف | API |
| --- | --- | --- |
| `▸ احذف ارتباط اللمّة بالمجموعة` | حذف لمّة: فشل إبدال / لهجية / ترجمة حرفية / لا تحمل المعنى | `remove_sense(sense_id)` |
| `▸ أشر إلى مفهوم أجنبي لا مقابل له` | مفهوم معجمي أجنبي لا صلة له بالسياق العربي | `set_metadata("synset", id, "cultural_fit", "omission")` |

### ٤. أوامر بنيوية وتقييمية (Structural & Eval)

| الأمر | الوصف | API |
| --- | --- | --- |
| `▸ أشر إلى فجوة معجمية` | لا يوجد مقابل عربي مفرد لهذا المفهوم | `set_metadata("synset", id, "cultural_fit", "lexical_gap")` |
| `▸ أشر إلى ضرورة فصل المجموعة` | المجموعة تخلط بين معاني متعددة | `create_synset()` + `move_sense()` + `add_synset_relation()` |
| `▸ أشر إلى ضرورة مراجعة التعريف` | أدلة الخطوة ٠ تشير إلى أن التعريف ضيّق أو خاطئ | *(إشارة داخلية للخطوة ٣)* |
| `▸ أشر إلى خطأ نوع الكلمة` | اسم مصنّف كفعل، أو العكس | `update_entry(id, pos=)` / `update_synset(id, pos=)` |
| `▸ أقرّ صحة العلاقات` | العلاقات الهرمية صحيحة ومنطقية | *(تحليلي)* |
| `▸ صعّد للمراجع البشري` | حالة معقدة/تعارض شواهد يستدعي تدخل مراجع خبير | `set_metadata("synset", id, "escalation", reason)` + `set_confidence("synset", id, 0.0)` |
| `▸ أكّد صلاحية اللمّة` | اللمّة صحيحة، مدعومة معجمياً، وتناسب المجموعة | `set_confidence("sense", sense_id, 1.0)` |
| `▸ ارفض المرشح` | المرشح المستخرج ليس مرادفاً حقيقياً | *(تحليلي — المرشح لم يُضف أصلاً)* |
| `▸ أبقِ التعريف كما هو` | التعريف سليم ولا يحتاج تعديلاً | *(تحليلي)* |
| `▸ اقترح مجموعة ترادفية جديدة` | المرشح أخصّ دلالياً ويستحق مجموعة جديدة | `create_synset()` + `create_entry()` + `add_sense()` + `add_synset_relation()` |
