# خوارزمية جمع الشواهد المعجمية
# Evidence Collection Algorithm (v2)

> **المبدأ:** هذه الوحدة تحوّل المراجع إلى **باحث** فقط. يجمع مادة خام من قاعدة البيانات دون أي تحليل أو حكم. المخرج الوحيد هو **القطعة الشاهدية** (`{synset_id}.evidence.yaml`).

> **Principle:** This module transforms the reviewer into a **researcher** only. They collect raw material from the database without any analysis or judgment. The sole output is the **evidence artifact** (`{synset_id}.evidence.yaml`).

> **المرجع:** بنية المخرج محددة في `EVIDENCE_SCHEMA.yaml`. قوالب SQL في `SQL_QUERIES.sql`.

---

## الاصطلاحات — Conventions

```
لكل X في Y نفّذ          FOR EACH X in Y DO
إذا ... فـ               IF ... THEN
وإلا                     ELSE
نهاية                    END
⟵                        تعيين (assignment)
▸ استعلم(...)            تنفيذ استعلام SQL
▸ سجّل(حقل، ...)        تسجيل النتيجة الخام
▸ أثرِ(...)              إثراء الإدخالات بجداول فرعية (child tables)
┊                        مستوى التداخل (indentation)
```

---

## المُدخل — Input

```
مجموعة_ترادفية = {
    معرّف:          "awn4-XXXXXXXX-X"
    لمّات:          [لمّة₁، لمّة₂، ...]
    تعريف_عربي:     "..."
    أمثلة_عربية:    ["..."]
    نوع:            اسم | فعل | صفة | ظرف
    ili:            "iNNNNNN" | null
    علاقات:         [{نوع، هدف}, ...]
}
```

---

## المُخرج — Output

```
ملف YAML واحد: {synset_id}.evidence.yaml
البنية محددة في: EVIDENCE_SCHEMA.yaml
```

**القواعد — Rules:**
1. كل حقل = نتيجة استعلام خام أو حساب ميكانيكي
2. ممنوع: أحكام، تقييمات، تصنيفات، ملاحظات تفسيرية
3. النص الكامل دائماً — لا اقتطاع
4. كل خطوة تُسجَّل مع قالب SQL ومعاملاته

## الخوارزمية

```
لكل مجموعة_ترادفية في قائمة_المراجعة نفّذ

    القطعة ⟵ قطعة_فارغة(مجموعة_ترادفية.معرّف)

    // ══════════════════════════════════════════════
    // § _meta — بيانات وصفية
    // ══════════════════════════════════════════════

    ▸ سجّل(القطعة._meta، {
        schema_version: "1.0.0",
        generated_at:   الطابع_الزمني_الحالي(),
        generator:      "manual",
        db_path:        "data/arabic_dict.db",
        db_stats:       ▸ استعلم(HELPER: Database Stats)
    })

    // ══════════════════════════════════════════════
    // § synset — معلومات المجموعة
    // ══════════════════════════════════════════════

    ▸ سجّل(القطعة.synset، {
        id, ili, pos, lemmas, definition_ar, examples_ar
    })

    إذا مجموعة_ترادفية.ili ≠ null فـ
        بيانات_OEWN ⟵ استعلم_OEWN(ili)
        ▸ سجّل(القطعة.synset.oewn، بيانات_OEWN)
    نهاية

    // ── سلسلة الأعمّ إلى الجذر — Hypernym Chain to Root ──
    // Uses wn library: synset.hypernym_paths()
    // Traverses both "hypernym" and "instance_hypernym" relations.
    مسارات ⟵ مجموعة_ترادفية.hypernym_paths()
    إذا مسارات ≠ [] فـ
        أقصر_مسار ⟵ min(مسارات، key=len)
        لكل سلف في أقصر_مسار نفّذ
            بيانات_en ⟵ استعلم_OEWN_عبر_ILI(سلف.ili) إن وُجد
            ▸ سجّل(القطعة.synset.hypernym_chain.path، {
                id, lemmas, definition_ar,
                oewn_definition_en, oewn_lemmas_en
            })
        نهاية
        القطعة.synset.hypernym_chain.depth ⟵ طول(أقصر_مسار)
    نهاية

    لكل علاقة في مجموعة_ترادفية.علاقات نفّذ
        هدف ⟵ استعلم_AWN4(علاقة.هدف)
        ▸ سجّل(القطعة.synset.relations، {
            rel_type, target_id, target_lemmas,
            target_definition_ar, target_oewn_*
        })
    نهاية

    // ══════════════════════════════════════════════
    // الخطوات لكل لمّة (١، ٢، ٣، ٦، ٧، ٨)
    // ══════════════════════════════════════════════

    جميع_المعرّفات ⟵ {}   // لتتبع entry_ids عبر الخطوات

    لكل لمّة في مجموعة_ترادفية.لمّات نفّذ

        // ── الهوية ──
        عارية ⟵ جرّد_التشكيل(لمّة)
        مُطبّعة ⟵ طبّع_العربية(لمّة)    // ة→ه، ى→ي
        متعددة ⟵ يحتوي_مسافة(لمّة)
        مكوّنات ⟵ إذا متعددة: قسّم(لمّة) وإلا: []

        ▸ سجّل(القطعة.per_lemma[لمّة].identity، {
            lemma: لمّة,
            lemma_bare: عارية,
            lemma_norm: مُطبّعة,
            is_multiword: متعددة,
            components: مكوّنات
        })

        // ────────────────────────────────────
        // الخطوة ١: المطابقة الدقيقة (مع أل التعريف)
        // Step 1: Exact Headword Lookup (ال-aware)
        // ────────────────────────────────────
        // ~20% من الإدخالات (154K) تحتوي على ال في headword_norm.
        // المعاجم الكلاسيكية (OCR) تُدرج الأسماء بأل: "المَلَاذُ" لا "ملاذ".
        // بدون هذا، أغنى الإدخالات تكون مخفية.
        مُطبّعة_بأل ⟵ 'ال' || مُطبّعة   // definite article variant
        صيغ_ال ⟵ [مُطبّعة، مُطبّعة_بأل]
        نتائج_١ ⟵ ▸ استعلم(STEP 1، مُطبّعة، مُطبّعة_بأل)
        ▸ أثرِ(نتائج_١)     // إثراء بالجداول الفرعية الست
        ▸ سجّل(القطعة.per_lemma[لمّة].step1_headword، {
            al_variants_searched: صيغ_ال,
            sql_template, query_params, result_count, entries: نتائج_١
        })

        // إذا اللمّة متعددة الكلمات → أضف نتائج المكوّنات (ال-aware أيضاً)
        إذا متعددة فـ
            لكل كلمة في مكوّنات نفّذ
                كلمة_م ⟵ طبّع(كلمة)
                نتائج_مكوّن ⟵ ▸ استعلم(STEP 1، كلمة_م، 'ال' || كلمة_م)
                ▸ أثرِ(نتائج_مكوّن)
                ▸ سجّل(القطعة.per_lemma[لمّة].step1_headword.by_component[كلمة]، {
                    sql_template, query_params, result_count, entries: نتائج_مكوّن
                })
            نهاية
        نهاية

        جميع_المعرّفات ⟵ جميع_المعرّفات ∪ {e.entry_id لكل e في نتائج_١}

        // ────────────────────────────────────
        // الخطوة ٢: التعريفات المُهيكلة (ال-aware)
        // ────────────────────────────────────
        نتائج_٢ ⟵ ▸ استعلم(STEP 2، مُطبّعة، مُطبّعة_بأل)
        ▸ سجّل(القطعة.per_lemma[لمّة].step2_definitions، {
            sql_template, query_params, result_count,
            entries_with_senses: نتائج_٢
        })

        // ────────────────────────────────────
        // الخطوة ٣: عائلة الجذر (مُعزَّزة)
        // Step 3: Root Family (Enhanced)
        // ────────────────────────────────────

        // (أ) استنتاج الجذر — ال-aware
        // يبحث في عمود root لإدخالات headword_norm IN (مُطبّعة, مُطبّعة_بأل)
        // الأولوية: ocr > lane > camel (OCR أدق من Lane لأن Lane يخطئ أحياناً)
        // مثال: الإدخال "الملاذ" من الوسيط يعطي جذر "لوذ" الصحيح
        //        بينما إدخال ARABTERM "ملاذ" أعطى جذر "ملذ" الخطأ
        جذور ⟵ ▸ استعلم(STEP 3a، مُطبّعة، مُطبّعة_بأل)
        ▸ سجّل(القطعة.per_lemma[لمّة].step3_root_family.roots_found، جذور)

        // (ب) إدخالات العائلة لكل جذر
        // يبحث في عمود root وكذلك headword_norm = الجذر
        // هذا يلتقط إدخالات الحوراني حيث العنوان = الجذر (مثل: عنوان "لوذ")
        // لكن عمود root فارغ (NULL)
        لكل جذر في جذور نفّذ
            نتائج_عائلة ⟵ ▸ استعلم(STEP 3b، جذر.root، معرّفات_الخطوة_١)
            ▸ أثرِ(نتائج_عائلة)
            ▸ سجّل(القطعة.per_lemma[لمّة].step3_root_family.by_root[جذر.root]، {
                sql_template, query_params, result_count, entries: نتائج_عائلة
            })
            جميع_المعرّفات ⟵ جميع_المعرّفات ∪ {e.entry_id لكل e في نتائج_عائلة}
        نهاية

        // ────────────────────────────────────
        // الخطوة ٦: الشواهد (ال-aware)
        // ────────────────────────────────────
        نتائج_٦ ⟵ ▸ استعلم(STEP 6، مُطبّعة، مُطبّعة_بأل)
        ▸ سجّل(القطعة.per_lemma[لمّة].step6_examples، {
            sql_template, query_params, result_count, examples: نتائج_٦
        })

        // ────────────────────────────────────
        // الخطوة ٧: الترتيب الزمني (ال-aware)
        // ────────────────────────────────────
        // نفس إدخالات الخطوة ١ (ال-aware) مرتبة زمنياً
        نتائج_٧ ⟵ ▸ استعلم(STEP 7، مُطبّعة، مُطبّعة_بأل)
        ▸ أثرِ(نتائج_٧)
        ▸ سجّل(القطعة.per_lemma[لمّة].step7_chronological، {
            sql_template, query_params, result_count, entries: نتائج_٧
        })

        // ────────────────────────────────────
        // الخطوة ٨: البحث العكسي (مُعزَّز)
        // Step 8: Reverse Lookup (Enhanced)
        // ────────────────────────────────────
        // يبحث FTS في headword + headword_bare + definitions_text
        // (لا definitions_text فقط كما كان سابقاً)
        // هذا يلتقط المورد الحديث حيث العنوان يحتوي سلاسل مرادفات:
        //   "(1) ملاذ؛ ملجأ؛ مفزع" — headword يحتوي على اللمّة
        // الاستبعاد ال-aware: يستبعد headword_norm IN (مُطبّعة, مُطبّعة_بأل)
        نتائج_٨ ⟵ ▸ استعلم(STEP 8، لمّة، مُطبّعة، مُطبّعة_بأل)
        ▸ أثرِ(نتائج_٨)
        ▸ سجّل(القطعة.per_lemma[لمّة].step8_reverse_lookup، {
            sql_template, query_params, result_count, entries: نتائج_٨
        })
        جميع_المعرّفات ⟵ جميع_المعرّفات ∪ {e.entry_id لكل e في نتائج_٨}

    نهاية  // لكل لمّة

    // ══════════════════════════════════════════════
    // الخطوات على مستوى المجموعة (٤، ٥، ٩)
    // ══════════════════════════════════════════════

    // ────────────────────────────────────
    // الخطوة ٤: البحث النصي الكامل
    // ────────────────────────────────────
    كلمات_مفتاحية ⟵ استخلص_رموز_عربية(مجموعة_ترادفية.تعريف_عربي)
    // أزِل الكلمات الوظيفية (من، في، على، إلى، ...)
    كلمات_مفتاحية ⟵ أزِل_الوقفات(كلمات_مفتاحية)

    تعبير_FTS ⟵ اربط_بـ_OR(كلمات_مفتاحية)
    نتائج_٤ ⟵ ▸ استعلم(STEP 4، تعبير_FTS، جميع_المعرّفات)
    ▸ أثرِ(نتائج_٤)
    ▸ سجّل(القطعة.per_synset.step4_fts_keyword، {
        keywords_extracted: كلمات_مفتاحية,
        sql_template, query_params,
        excluded_entry_ids: قائمة(جميع_المعرّفات),
        result_count, entries: نتائج_٤
    })
    جميع_المعرّفات ⟵ جميع_المعرّفات ∪ {e.entry_id لكل e في نتائج_٤}

    // ────────────────────────────────────
    // الخطوة ٥: الجسر الإنجليزي
    // ────────────────────────────────────
    إذا القطعة.synset.oewn ≠ null فـ
        مصطلحات ⟵ القطعة.synset.oewn.lemmas_en
        لكل مصطلح في مصطلحات نفّذ
            نتائج_٥ ⟵ ▸ استعلم(STEP 5، مصطلح، جميع_المعرّفات)
            ▸ أثرِ(نتائج_٥)
        نهاية
        ▸ سجّل(القطعة.per_synset.step5_english_bridge، {
            english_terms_used: مصطلحات,
            sql_template, query_params,
            excluded_entry_ids, result_count,
            entries: دمج_وتكرير(جميع_نتائج_٥)
        })
        جميع_المعرّفات ⟵ جميع_المعرّفات ∪ {e.entry_id لكل e في نتائج_٥}
    نهاية

    // ────────────────────────────────────
    // الخطوة ٩: التصفية التخصصية
    // ────────────────────────────────────
    مرشحات ⟵ []

    // (أ) تصفية حسب الصنف — إذا الجذر متعدد الأصناف
    إذا يوجد_جذر AND نتائج_العائلة تتضمن أصنافاً مختلفة فـ
        نتائج_٩أ ⟵ ▸ استعلم(STEP 9a، جذر، صنف_المجموعة)
        ▸ أثرِ(نتائج_٩أ)
        مرشحات.أضِف({filter_type: "pos", ...})
    نهاية

    // (ب) تصفية حسب المجال — إذا اللمّة تقنية
    إذا يوجد_مجال_ARABTERM فـ
        نتائج_٩ب ⟵ ▸ استعلم(STEP 9b، المجال، مُطبّعة)
        ▸ أثرِ(نتائج_٩ب)
        مرشحات.أضِف({filter_type: "domain", ...})
    نهاية

    ▸ سجّل(القطعة.per_synset.step9_specialized، {
        filters_applied: مرشحات
    })

    // ══════════════════════════════════════════════
    ▸ احفظ(القطعة، "{synset_id}.evidence.yaml")
    // ═══ انتهى جمع الشواهد ═══

نهاية  // لكل مجموعة ترادفية
```

## الإجراء الفرعي: أثرِ — Enrich Entries

```
دالة أثرِ(إدخالات):
    // إثراء مجموعة إدخالات بجميع الجداول الفرعية
    // يُنفَّذ دفعة واحدة (batch) لا إدخالاً بإدخال

    معرّفات ⟵ {e.entry_id لكل e في إدخالات}

    تعريفات ⟵ ▸ استعلم(ENRICH: Definitions، معرّفات)
    شواهد ⟵ ▸ استعلم(ENRICH: Examples، معرّفات)
    جموع ⟵ ▸ استعلم(ENRICH: Plurals، معرّفات)
    مشتقات ⟵ ▸ استعلم(ENRICH: Derived Forms، معرّفات)
    إحالات ⟵ ▸ استعلم(ENRICH: Cross References، معرّفات)
    مصادر ⟵ ▸ استعلم(ENRICH: Provenance، معرّفات)

    لكل e في إدخالات نفّذ
        e.definitions ⟵ صفّ(تعريفات، e.entry_id)
        e.examples ⟵ صفّ(شواهد، e.entry_id)
        e.plurals ⟵ صفّ(جموع، e.entry_id)
        e.derived_forms ⟵ صفّ(مشتقات، e.entry_id)
        e.cross_refs ⟵ صفّ(إحالات، e.entry_id)
        e.provenance ⟵ صفّ_واحد(مصادر، e.entry_id)   // one-to-one
    نهاية

نهاية_الدالة
```

## الإجراء الفرعي: استنتج الجذر — Root Inference

```
دالة استنتج_الجذر(لمّة):
    مُطبّعة ⟵ طبّع(لمّة)
    مُطبّعة_بأل ⟵ 'ال' || مُطبّعة

    // الطريقة ١: البحث في قاعدة البيانات (ال-aware)
    // يبحث في headword_norm IN (مُطبّعة, مُطبّعة_بأل)
    // الأولوية: ocr > lane > camel
    //   OCR أدق: الوسيط يعطي "لوذ" لـ"المَلَاذُ"
    //   Lane يخطئ أحياناً: أعطى "ملذ" لـ"ملاذ" في ARABTERM
    نتائج ⟵ ▸ استعلم(STEP 3a، مُطبّعة، مُطبّعة_بأل)
    إذا نتائج غير فارغة فـ
        أعد نتائج    // جميع الأزواج (root, root_source) كما هي

    // الطريقة ٢: التجريد الصرفي (ميكانيكي)
    وإلا إذا لمّة تطابق وزناً معروفاً فـ
        جذر_مرشح ⟵ جرّد_حسب_الوزن(لمّة)
        تأكيد ⟵ ▸ استعلم(STEP 3a، مشتقات(جذر_مرشح))
        إذا تأكيد فـ
            أعد [{root: جذر_مرشح, root_source: "morphological_inference"}]

    // الطريقة ٣: لا جذر
    وإلا
        أعد []    // فارغ — ربما لفظ مقترض
    نهاية

نهاية_الدالة
```

## الفروق عن الخوارزميات السابقة

### v1 → v2

| العنصر | v1 (القديمة) | v2 |
|--------|-------------|-------------|
| الخطوة ٢ | `مطابق: صحيح/خطأ` + `تشويش` | نص التعريف الخام فقط |
| الخطوة ٣ | `مرشحات: [...]` (مشتقات مُقيَّمة) | `by_root: {entries: [...]}` (خام) |
| الخطوة ٦ | `بالمعنى: صحيح/خطأ` | جميع الشواهد بلا تصفية |
| الخطوة ٧ | `تصنيف: مستقر/توسيع/...` | إدخالات مرتبة بـ death_year — بلا تصنيف |
| الخطوة ٨ | `مرشحات_المرادف: [{ملاحظة}]` | `entries: [...]` بلا تسميات |
| الإثراء | examples فقط | ٦ جداول: definitions, examples, plurals, derived_forms, cross_refs, provenance |
| الأعمدة | ١٢ عموداً | ٢٢ عموداً (أُضيفت: form, external_id, translation_fr, headword_norm, dict_author, dict_death_year, is_partial, dict_name_ar) |
| التتبع | بلا | sql_template + query_params لكل خطوة |
| التقاطع | ملحوظات نثرية | مُشتَق من الإدخالات لكل خطوة |
| المخرج | Markdown | YAML مُهيكل |

### v2 → v3 (الحالية — Enhanced Extraction)

| العنصر | v2 | v3 (الحالية) |
|--------|-----|-------------|
| الخطوة ١ | `WHERE headword_norm = ?` | `WHERE headword_norm IN (?, 'ال' \|\| ?)` — يلتقط ~154K إدخال بأل التعريف |
| الخطوة ٣أ | أولوية: lane > ocr > camel | أولوية: `ocr > lane > camel` — OCR أدق (Lane يخطئ أحياناً) |
| الخطوة ٣أ | بحث في headword_norm = ? فقط | بحث ال-aware: `IN (?, 'ال' \|\| ?)` |
| الخطوة ٣ب | `WHERE root = ?` فقط | `WHERE (root = ? OR headword_norm = ?)` — يلتقط إدخالات الحوراني حيث العنوان = الجذر |
| الخطوة ٨ | FTS في definitions_text فقط | FTS في `{headword headword_bare definitions_text}` — يلتقط المورد الحديث |
| الخطوة ٨ | استبعاد: `headword_norm != ?` | استبعاد ال-aware: `NOT IN (?, 'ال' \|\| ?)` |
| الخطوة ٨ | LIMIT 50 | LIMIT 100 |
| جميع الخطوات | بلا `al_variants_searched` | حقل `al_variants_searched` في الخطوة ١ للتتبع |
