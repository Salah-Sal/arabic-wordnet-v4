# دليل المراجعة اليدوية — Manual Synset Review Guide

> دليل مستقل للمراجع اللغوي يتّبع منهجية ذات مرحلتين: **بحث معجمي** ثم **تحليل لغوي**.
> لا يعتمد هذا الدليل على أي خط أنابيب آلي — كل شيء يبدأ من معرّف المجموعة الترادفية وقاعدة بيانات المعاجم.

---

## 0. المقدمة — Introduction

### ما هذا المشروع؟ — What Is This Project?

الشبكة العربية للكلمات (AWN 4.0) قاعدة بيانات معجمية تضم أكثر من **109,000 مجموعة ترادفية (Synset)**، تم إنشاؤها عبر ترجمة "شبكة الكلمات الإنجليزية المفتوحة" (OEWN 2024) باستخدام الذكاء الاصطناعي (Google Gemini). الهدف توفير مورد لغوي مفتوح المصدر للعربية يغطي الأسماء والأفعال والصفات والظروف مع ربطها بالمفاهيم العالمية.

### ما دور المراجع؟ — What Is the Reviewer's Role?

بما أن المحتوى مُولَّد آلياً، فالحاجة ماسة لعين خبيرة بشرية. دورك ليس مجرد "التصحيح" بل **الإثراء والتوطين الدلالي** (Semantic Localization) — تحويل ترجمة آلية خام إلى مورد معجمي عربي أصيل. نحن نبني شبكة مفاهيم عربية، لا مجرد قاموس ثنائي اللغة.

### منهجية المرحلتين — The Two-Stage Workflow

| المرحلة | الهدف | المخرج |
|---------|-------|--------|
| **١. البحث المعجمي وجمع المادة** | استرجاع كل ما يتصل بالمجموعة الترادفية من قاعدة بيانات المعاجم (760,660 مدخلاً من 107 معجماً) | ملف بحثي منظّم (research dossier) |
| **٢. التحليل اللغوي** | اتخاذ القرارات اللغوية بناءً على المادة المجموعة | ملف YAML بالقرارات النهائية |

> **لماذا مرحلتان؟** فصل جمع المادة عن التحليل يضمن أن القرارات مبنية على شواهد كاملة لا على انطباعات أولية. اجمع أولاً، ثم حلّل.

### ما تحتاجه — Prerequisites

| المتطلب | الوصف |
|---------|------|
| **قاعدة البيانات** | ملف `arabic_dict.db` (≈311 ميغابايت) |
| **أداة SQL** | sqlite3 CLI |
| **بيانات AWN4** | ملف `awn4.xml` أو واجهة استعراض المجموعات |
| **معرفة لغوية** | علم الصرف والدلالة العربية |

## 1.2 هيكل قاعدة البيانات — Database Structure

```
dictionaries (107 معجماً)
    └── entries (760,660 مدخلاً)
            ├── definitions  (614,227 تعريفاً)
            ├── examples     (86,031 شاهداً)
            ├── plurals      (24,466 جمعاً)
            ├── derived_forms (50,191 مشتقاً)
            ├── cross_refs   (10,453 إحالة)
            └── provenance   (552,601 مصدراً)
```

### المصادر الثلاثة — Three Data Sources

| المصدر | المعاجم | المداخل | POS؟ | أمثلة؟ | ترجمات؟ |
|--------|:-------:|--------:|:----:|:------:|:-------:|
| **OCR** (استخلاص بصري) | 5 | 109,769 | نعم | نعم | لا |
| **Hawramani** (تصدير رسمي) | 51 | 233,465 | جزئي | جزئي | لا |
| **ARABTERM** (مصطلحات تقنية) | 51 | 417,426 | لا | لا | نعم (EN/FR) |

### الجداول الرئيسية — Key Tables

#### `dictionaries` — فهرس المعاجم

| العمود | الوصف | مثال |
|--------|------|------|
| `id` | المعرّف | `1` |
| `key` | مفتاح فريد | `Al_Waseet` |
| `name_ar` | الاسم بالعربية | المعجم الوسيط |
| `name_en` | الاسم بالإنجليزية | Al-Mu'jam Al-Wasit |
| `source_type` | نوع المصدر | `ocr` / `hawramani` / `arabterm` |
| `period` | العصر | `classical` / `modern` |
| `death_year` | سنة وفاة المؤلف | `1311` (ابن منظور) |

#### `entries` — المداخل الموحّدة

| العمود | الوصف | مثال |
|--------|------|------|
| `id` | المعرّف | `42` |
| `dictionary_id` | FK إلى `dictionaries` | `3` |
| `headword` | الكلمة الرئيسية **بالتشكيل** | كَتَبَ |
| `headword_bare` | بدون تشكيل | كتب |
| `headword_norm` | مطبّعة (همزة/ألف موحّدة) | كتب |
| `root` | الجذر الثلاثي/الرباعي | كتب |
| `root_source` | مصدر الجذر | `ocr` / `lane` / `camel` |
| `pos` | نوع الكلمة | `noun` / `verb` / `adj` |
| `form` | الوزن الصرفي (للأفعال) | `I` / `IV` / `VIII` / `Q` |
| `definitions_text` | التعريفات مسطّحة (للبحث النصي) | الكِتَابَ: خَطَّهُ... |
| `translation_en` | ترجمة إنجليزية (ARABTERM فقط) | `book` |
| `translation_fr` | ترجمة فرنسية (ARABTERM فقط) | `livre` |
| `domain` | المجال التخصصي (ARABTERM فقط) | `Biology` |

#### `definitions` — التعريفات المهيكلة

| العمود | الوصف |
|--------|------|
| `entry_id` | FK إلى `entries` |
| `sense_index` | ترتيب المعنى (0، 1، 2...) |
| `text` | نص التعريف |
| `is_raw` | 1 = نص خام من Hawramani |

#### `examples` — الشواهد

| العمود | الوصف |
|--------|------|
| `entry_id` | FK إلى `entries` |
| `type` | النوع: `quran` / `poetry` / `hadith` / `proverb` / `usage` |
| `text` | نص الشاهد |
| `attribution` | النسبة (الشاعر، السورة، إلخ.) |

### مستويات تطبيع الكلمة الرئيسية — Headword Normalization

| المستوى | العمود | ما يفعله | مثال: أحمد | مثال: مُسْتَشْفَى |
|---------|--------|---------|-----------|----------------|
| الأصلي | `headword` | يحتفظ بكل التشكيل | أَحْمَدُ | مُسْتَشْفَى |
| مجرّد | `headword_bare` | يزيل التشكيل فقط | أحمد | مستشفى |
| مطبّع | `headword_norm` | يزيل التشكيل + يوحّد الهمزة/الألف + يحوّل ى→ي | احمد | مستشفي |

**قواعد التطبيع:**

```
أ / إ / آ  →  ا      (الهمزات فوق/تحت الألف → ألف مجرّدة)
ى         →  ي      (الألف المقصورة → ياء)
ـ          →  (حذف)   (التطويل يُزال)
```

**متى تستخدم كل مستوى؟**

| الموقف | العمود المناسب |
|--------|--------------|
| تعرف الإملاء الدقيق | `headword_bare` |
| لا تعرف شكل الهمزة | `headword_norm` |
| تريد التشكيل الأصلي | `headword` |

## 1.3 بروتوكول البحث — Research Protocol

> **التعليمات:** لكل مجموعة ترادفية، كرّر الخطوات التالية على **كل لمّة** (lemma) فيها على حدة. ابدأ باللمّة الأولى ونفّذ الخطوات بالترتيب، ثم انتقل إلى اللمّة التالية وهكذا. بعد الانتهاء من جميع اللمّات، نفّذ الخطوات المشتركة (كالبحث النصي والجسر الإنجليزي) على مستوى المجموعة ككل.

### الخطوة 1: المطابقة الدقيقة — Exact Headword Lookup

**الغرض:** رؤية كيف تعرّف جميع المعاجم نفس الكلمة — بتعريفات كاملة.

```sql
-- لكل لمّة في المجموعة الترادفية:
SELECT d.name_ar, d.death_year, d.period, d.source_type
FROM entries e
JOIN dictionaries d ON e.dictionary_id = d.id
WHERE e.headword_norm = 'مال'
ORDER BY d.death_year;
```

**ماذا تسجّل:** عدد المعاجم التي تحتوي اللمّة. هل موجودة في الكلاسيكي والحديث معاً؟

---

### الخطوة 2: التعريفات الكاملة — Full Definitions

**الغرض:** استرجاع النص الكامل للتعريفات (بدون اقتطاع) لكل معنى.

```sql
-- التعريفات المهيكلة حسب المعنى
SELECT d.name_ar, d.death_year, df.sense_index, df.text
FROM entries e
JOIN dictionaries d ON e.dictionary_id = d.id
JOIN definitions df ON df.entry_id = e.id
WHERE e.headword_norm = 'مال'
ORDER BY d.death_year, e.id, df.sense_index;
```

**نسخة مبسّطة** (التعريفات المسطّحة — كل المعاني في نص واحد):

```sql
SELECT d.name_ar, d.period, d.death_year, e.pos, e.definitions_text
FROM entries e
JOIN dictionaries d ON e.dictionary_id = d.id
WHERE e.headword_norm = 'مال'
ORDER BY d.death_year, d.name_en;
```

**ماذا تسجّل:** التعريفات التي تطابق معنى المجموعة الترادفية. أي تعريفات لمعانٍ مختلفة (= تشويش).

> **تلميح:** استخدم جدول `definitions` مع `sense_index` لفصل المعاني. الحقل `definitions_text` يدمج كل المعاني في نص واحد.

---

### الخطوة 3: عائلة الجذر — Root Family Exploration

**الغرض:** إيجاد كل الكلمات المشتقة من جذر واحد عبر جميع المعاجم.

```sql
-- كل المداخل من نفس الجذر
SELECT e.headword_bare, e.pos, e.form, d.name_ar,
       SUBSTR(e.definitions_text, 1, 150) AS def_preview
FROM entries e
JOIN dictionaries d ON e.dictionary_id = d.id
WHERE e.root = 'مول'
ORDER BY e.pos, e.headword_bare, d.death_year;
```

**نسخة مختصرة** — الكلمات الفريدة فقط مع عدد المعاجم:

```sql
SELECT e.headword_bare, e.pos,
       COUNT(DISTINCT d.id) AS dict_count,
       GROUP_CONCAT(DISTINCT d.name_ar) AS dictionaries
FROM entries e
JOIN dictionaries d ON e.dictionary_id = d.id
WHERE e.root = 'مول'
GROUP BY e.headword_bare, e.pos
ORDER BY dict_count DESC;
```

**ماذا تسجّل:** المشتقات التي قد تكون مرادفات مفقودة. العلاقات الاشتقاقية.

#### كيف تستنتج الجذر؟ — How to Deduce the Root

بيانات المجموعة الترادفية لا تتضمن الجذر، لذا عليك استنتاجه قبل البحث. استخدم الطرق التالية بالترتيب:

**الطريقة ١: البحث في قاعدة البيانات** — ابحث عن اللمّة نفسها واسترجع الجذر المسجّل:

```sql
SELECT DISTINCT root, root_source FROM entries
WHERE headword_norm = 'تمويل' AND root IS NOT NULL;
```

> قاعدة البيانات تحتوي جذوراً من ثلاثة مصادر (`root_source`): معالجة OCR (`ocr`)، معجم لين (`lane`)، ومحلل CAMeL (`camel`). إذا اختلفت المصادر، رجّح `lane` ثم `ocr` ثم `camel`.

**الطريقة ٢: التجريد الصرفي** — إذا لم تجد اللمّة في قاعدة البيانات، جرّد الكلمة يدوياً بتطبيق قواعد الصرف العربي:

| الوزن | المثال | الجذر |
|-------|--------|-------|
| تَفْعِيل | تمويل | م-و-ل |
| اسْتِفْعال | استخراج | خ-ر-ج |
| مُفاعَلة | مُشاركة | ش-ر-ك |
| فاعِل | كاتِب | ك-ت-ب |
| مَفْعُول | مكتوب | ك-ت-ب |
| فَعّال | خبّاز | خ-ب-ز |
| أَفْعَل (تفضيل) | أكبر | ك-ب-ر |
| فِعالة (مصدر) | كتابة | ك-ت-ب |

> **تنبيه:** بعض الأوزان تتشابه — «مِفْتاح» وزنها مِفْعال (جذر: ف-ت-ح) لا مُفَعَّل. تحقق دائماً بالطريقة ١ بعد استنتاجك.

**الطريقة ٣: الاستنتاج اللغوي المباشر** — بصفتك لغوياً متخصصاً، يمكنك استنتاج الجذر مباشرة من معرفتك الصرفية دون الحاجة لأداة. جرّد الزوائد (أحرف الزيادة: سألتمونيها) وحدّد الأصول الثلاثة أو الأربعة. مثلاً: «استغفار» → أزل «ا-س-ت» و«ا» → غ-ف-ر.

### الخطوة 4: البحث النصي الكامل — Full-Text Definition Search (FTS5)

**الغرض:** إيجاد مداخل تحتوي تعريفاتها على كلمات مفتاحية — للعثور على مفاهيم مرتبطة بكلمات مختلفة.

```sql
SELECT e.headword_bare, d.name_ar,
       SUBSTR(e.definitions_text, 1, 200) AS def_preview
FROM entries e
JOIN dictionaries d ON e.dictionary_id = d.id
JOIN entries_fts ON e.id = entries_fts.rowid
WHERE entries_fts MATCH '"ثروة" OR "نقود"'
ORDER BY rank
LIMIT 30;
```

**ماذا تسجّل:** كلمات تتقاطع مع المفهوم — مرشحات كمرادفات أو ألفاظ متصلة.

> **مهم:** لفّ الكلمات العربية بعلامتي تنصيص `"..."` دائماً — لتفادي أخطاء بناء جملة FTS5. انظر §1.4 لتفاصيل بناء الجملة.

### الخطوة 5: الجسر الإنجليزي — English Translation Bridge (ARABTERM)

**الغرض:** إيجاد المصطلحات العربية التقنية عبر مقابلها الإنجليزي.

```sql
SELECT e.headword_bare, e.translation_en, e.translation_fr,
       e.domain, d.name_ar
FROM entries e
JOIN dictionaries d ON e.dictionary_id = d.id
JOIN entries_translations_fts ON e.id = entries_translations_fts.rowid
WHERE entries_translations_fts MATCH '"money" OR "currency"'
ORDER BY rank
LIMIT 20;
```

**ماذا تسجّل:** مصطلحات تقنية مقابلة. تهجئات بديلة. المجالات التخصصية.

> **تحذير:** الكلمة الإنجليزية قد تكون متعددة المعاني — `"bank"` تجلب نتائج مصرفية وجغرافية. فلتر بالمجال:
> ```sql
> ... AND e.domain = 'Commerce and Accounting'
> ```

### الخطوة 6: الشواهد — Usage Examples

**الغرض:** إيجاد شواهد حقيقية (قرآنية، شعرية، حديثية) تستعمل الكلمة بالمعنى المقصود.

```sql
-- شواهد لكلمة محددة
SELECT e.headword_bare, ex.type, ex.text, ex.attribution, d.name_ar
FROM entries e
JOIN examples ex ON ex.entry_id = e.id
JOIN dictionaries d ON e.dictionary_id = d.id
WHERE e.headword_norm = 'مال'
  AND ex.type IN ('quran', 'hadith', 'poetry')
ORDER BY ex.type, d.death_year;
```

```sql
-- شواهد قرآنية لكل كلمات الجذر
SELECT e.headword_bare, ex.text
FROM entries e
JOIN examples ex ON ex.entry_id = e.id
WHERE e.root = 'مول' AND ex.type = 'quran'
ORDER BY e.headword_bare;
```

**أنواع الشواهد المتاحة:**

| النوع | العدد | الوصف |
|-------|------:|------|
| `poetry` | 49,747 | أبيات شعرية |
| `usage` | 16,811 | استعمال عام |
| `hadith` | 9,617 | أحاديث نبوية |
| `quran` | 7,411 | آيات قرآنية |
| `proverb` | 2,438 | أمثال عربية |

**ماذا تسجّل:** شواهد تستعمل الكلمة **بالمعنى المقصود** (لا بمعنى مجازي أو معنى آخر).

### الخطوة 7: التطور الزمني — Chronological Evolution

**الغرض:** تتبع كيف تطور معنى الكلمة من المعاجم الكلاسيكية إلى الحديثة.

```sql
SELECT d.death_year, d.name_ar, d.period, df.text AS definition
FROM entries e
JOIN dictionaries d ON e.dictionary_id = d.id
JOIN definitions df ON df.entry_id = e.id
WHERE e.headword_norm = 'مال'
  AND d.death_year IS NOT NULL
  AND df.sense_index = 0
ORDER BY d.death_year;
```

**المقارنة بين التراثي والحديث:**

```sql
SELECT d.period, d.name_ar, d.death_year,
       df.sense_index, df.text
FROM entries e
JOIN dictionaries d ON e.dictionary_id = d.id
JOIN definitions df ON df.entry_id = e.id
WHERE e.headword_norm = 'حاسوب'
ORDER BY d.period DESC, d.death_year;
```

**ماذا تبحث عنه:**

| الظاهرة | المؤشر | مثال |
|---------|--------|------|
| **توسيع دلالي** | المعنى الحديث أعم من القديم | «مال» كانت تعني الإبل فقط، ثم توسعت |
| **تضييق دلالي** | المعنى الحديث أخص من القديم | «سيّارة» كانت القافلة، ثم تخصصت |
| **انزياح دلالي** | المعنى تغيّر جذرياً | «لطيف» كانت = خفيّ/عالم بالدقائق، ثم أصبحت = ظريف |

> **ملاحظة:** غياب النتائج الكلاسيكية لكلمة ما معلومة مفيدة — يؤكد أنها مصطلح مولّد حديث.

### الخطوة 8: مرشحات المرادف — Synonym Candidate Discovery

**الغرض:** إيجاد كلمات أخرى تُذكر الكلمة المستهدفة في تعريفاتها (بحث عكسي).

```sql
SELECT e.headword_bare, d.name_ar,
       SUBSTR(e.definitions_text, 1, 200) AS def_preview
FROM entries e
JOIN dictionaries d ON e.dictionary_id = d.id
JOIN entries_fts ON e.id = entries_fts.rowid
WHERE entries_fts MATCH 'definitions_text:"مال"'
  AND e.headword_bare <> 'مال'
  AND d.source_type IN ('ocr', 'hawramani')
ORDER BY rank
LIMIT 20;
```

**ماذا تسجّل:** كلمات تُعرَّف بالكلمة المستهدفة — مرشحات قوية كمرادفات مفقودة.

> **تلميح:** البادئة `definitions_text:` تحصر البحث في عمود التعريفات فقط.

### الخطوة 9: التصفية حسب نوع الكلمة والوزن والمجال — Specialized Filtering

**POS والوزن الصرفي:**

```sql
SELECT e.headword, e.form, d.name_ar,
       SUBSTR(e.definitions_text, 1, 150) AS def_preview
FROM entries e
JOIN dictionaries d ON e.dictionary_id = d.id
WHERE e.root = 'كتب' AND e.pos = 'verb'
ORDER BY e.form, d.death_year;
```

**أوزان الأفعال المتاحة:**

| الوزن | العدد | الوزن | العدد |
|-------|------:|-------|------:|
| I (فَعَلَ) | 17,425 | VII (اِنْفَعَلَ) | 688 |
| II (فَعَّلَ) | 3,218 | VIII (اِفْتَعَلَ) | 1,685 |
| III (فَاعَلَ) | 1,375 | IX (اِفْعَلَّ) | 170 |

**المصطلحات التخصصية حسب المجال:**

```sql
SELECT e.headword_bare, e.translation_en, e.translation_fr
FROM entries e
JOIN dictionaries d ON e.dictionary_id = d.id
WHERE d.source_type = 'arabterm'
  AND e.domain = 'Biology'
  AND e.headword_bare LIKE '%خلي%'
ORDER BY e.headword_bare
LIMIT 30;
```

```sql
-- عرض المجالات المتاحة
```

## 1.4 بناء جملة FTS5 — FTS5 Query Syntax

| النمط | الصيغة | مثال | الشرح |
|-------|--------|------|-------|
| كلمة واحدة | `'"كلمة"'` | `'"مال"'` | يبحث عن الكلمة في أي عمود |
| عبارة حرفية | `'"كلمة1 كلمة2"'` | `'"جمع المال"'` | الكلمات متتالية بنفس الترتيب |
| OR (أيّ منها) | `'"أ" OR "ب"'` | `'"ثروة" OR "نقود"'` | أي واحدة من الكلمات |
| NOT (استبعاد) | `'"أ" NOT "ب"'` | `'"مال" NOT "ميل"'` | استبعاد معنى «الميل» |
| بادئة | `'كلم*'` | `'مال*'` | كل ما يبدأ بـ «مال» |
| عمود محدد | `'column:"كلمة"'` | `'definitions_text:"ثروة"'` | يبحث في عمود التعريفات فقط |

**ملاحظات مهمة:**

1. **التشكيل يُزال تلقائياً** — `كتب` تطابق `كَتَبَ` و`كِتَاب` و`كُتُب`.
2. **جدولان:** `entries_fts` (عربي) و `entries_translations_fts` (إنجليزي/فرنسي).
3. **الترتيب:** استخدم `ORDER BY rank` لأهمية BM25.
4. **لفّ الكلمات العربية بعلامات تنصيص دائماً.**

## 1.5 استراتيجية البحث — Research Strategy

### متى توسّع ومتى تضيّق — Broadening vs. Narrowing

| الموقف | الإجراء | مثال |
|--------|---------|------|
| نتائج قليلة | وسّع: من `headword_norm` إلى `root` إلى FTS5 | لم تجد «حاسوب» ← ابحث بالجذر «حسب» |
| نتائج كثيرة | ضيّق: أضف فلتر POS أو معجم | «مال» تجلب 50+ ← أضف `AND e.pos = 'noun'` |
| خلط معانٍ | ضيّق: استخدم NOT في FTS5 | «مال» تجلب «ميل» ← أضف `NOT "ميل"` |
| لا تطابق | وسّع: جرّب كلمات مفتاحية مختلفة | بدلاً من «ثروة» جرّب «نقود» أو «أموال» |

### التعامل مع الشواهد المتعارضة — Conflicting Evidence

| القاعدة | الشرح |
|---------|------|
| **للاستعمال المعاصر** ← الأولوية للمعاجم الحديثة | المعجم الوسيط، المعاصرة (أحمد مختار)، الدوحة |
| **للنواة الدلالية** ← الأولوية للمعاجم الكلاسيكية | لسان العرب، تاج العروس، القاموس المحيط |
| **سجّل كليهما** | لا تُهمل أياً من الشواهد |
| **عند عدم اليقين** ← صعّد | استخدم أمر `escalate` |

### ترتيب الحجية — Dictionary Authority Heuristic

| المصدر | الحجية | السبب |
|--------|:------:|------|
| معاجم كلاسيكية (Hawramani) | 1.00 | لسان العرب، تاج العروس — مراجع تراثية |
| معاجم OCR (مجمع اللغة) | 0.95 | المعجم الوسيط والكبير — معيارية حديثة |
| معاجم حديثة (Hawramani) | 0.85 | معاجم معاصرة |
| ARABTERM | 0.80 | تقنية — موثوقة في مجالها |

## 2.1 المنهجية التحليلية — The Investigative Methodology

عند تحليل أي مجموعة ترادفية، اتبع هذا التسلسل التحليلي الثابت:

| الخطوة | السؤال المحوري | الهدف |
|--------|---------------|-------|
| **1. التحقق من اللمّات** | هل كل لمّة تحمل فعلاً المعنى المقصود؟ | إثبات أو دحض صحة كل لمّة |
| **2. اكتشاف لمّات مفقودة** | هل هناك كلمات أخرى تحمل نفس المعنى لكنها غائبة؟ | توسيع المجموعة إن لزم |
| **3. تدقيق التعريف** | هل تعريف AWN يطابق المعاجم؟ أوسع؟ أضيق؟ | ضبط التعريف |
| **4. فحص العلاقات** | هل الأعلى (hypernym) والأدنى (hyponyms) صحيحة؟ | تأكيد أو تعديل الشبكة |

> **مبدأ أساسي:** لا تنتقل إلى الخطوة التالية قبل إتمام السابقة. **التحقق من اللمّات أولاً** — لأنه إذا كانت اللمّة خاطئة، فلا فائدة من تدقيق التعريف.

> **مخطط القرارات:** انظر `methodology_flow.svg` لمخطط بصري يوضح كل سؤال تحليلي والإجراءات الناتجة عنه.

## 2.2 الخطوة ١: التحقق من اللمّات — Lemma Verification

لكل لمّة في المجموعة الترادفية، أجب عن السؤال: **هل هذه الكلمة تحمل فعلاً هذا المعنى؟**

### أ. اختبار الإبدال — Substitution Test

> هل يمكن استبدال هذه اللمّة بلمّة أخرى في المجموعة داخل جملة دون تغيير المعنى؟

- إذا نجح الإبدال في السياقات المعتادة ← **مرادفة** ✓
- إذا فشل في **كل** سياق ← `reject_lemma` ✗

### ب. مبدأ منع الترادف التام — Anti-Synonymy Principle

> الترادف التام عزيز في العربية — فقلّما تجد كلمتين بمعنى واحد من كل وجه.

لكل لمّة ميزة أو ظل دلالي يخصها. حدّد هذا الفارق في حقل `nuance_note`.

مثال: لا تضع (سيف) و(صارم) و(مهنّد) في سلة واحدة دون تمييز — فالسيف اسم الجنس، والصارم من حيث هو قاطع، والمهنّد من حيث هو مصنوع في الهند.

### ج. اللفظ المختص أولى من اللفظ العام

إذا جاءك مفهوم "صوت الشجر"، لا تقبل (صوت) وهو اللفظ العام، بل اطلب (حفيف) وهو اللفظ المختص.

### د. سياسة التشكيل — Minimum Disambiguating Diacritics

- الشدة (ّ) حاضرة دائماً
- الحركات المطلوبة لتمييز المتجانسات فقط (مثال: بَرّ/بُرّ/بِرّ)
- لا نطلب تشكيلاً كاملاً

### هـ. إنفاذ الفصحى — Diglossic Enforcement

العربية الفصحى الحديثة (MSA) فقط. الأشكال اللهجية (مصرية، شامية، خليجية) يجب استبدالها بمقابلاتها الفصيحة.

### النتائج المحتملة — Decision Outcomes

| المسار | الشرط | الإجراء |
|--------|------|---------|
| **✓ تأكيد** | المعنى الأساسي مثبت في المعاجم | `confirm` |
| **⚠ ملاحظة** | المعنى مثبت لكن مع انزياح دلالي (كلاسيكي ≠ حديث) | `nuance_note: period restriction` |
| **◆ وسم** | الكلمة مولّدة حديثاً لا أصل كلاسيكي لها | `tag: usage=modern` |
| **✗ رفض** | الكلمة لا تحمل هذا المعنى مطلقاً | `reject_lemma` |

## 2.3 الخطوة ٢: اكتشاف لمّات مفقودة — Missing Lemma Discovery

باستخدام مرشحات المرادف من ملفك البحثي (المرحلة 1، الخطوة 8)، أجب: **هل هناك كلمات يجب أن تكون في المجموعة لكنها غائبة؟**

### اختبار الترادف الدائري — Circular Synonym Test

ابحث في FTS5: هل تعريف كلمة أ تذكر كلمة ب، والعكس؟ إذا نعم ← ترادف قوي.

### متى تضيف ومتى تقترح مجموعة جديدة

| حالة المرشح | الإجراء |
|-------------|---------|
| مرادف حقيقي (ينجح في اختبار الإبدال) | `add_lemma` |
| تهجئة بديلة لنفس الكلمة | `add_lemma (variant)` |
| مفهوم أخصّ (hyponym) | `propose_new_synset` |
| تشابه لفظي بدون تقارب دلالي | `reject_candidate` |
| لا مرشحين | المجموعة مكتملة |

## 2.4 الخطوة ٣: تدقيق التعريف — Definition Audit

قارن تعريف AWN مع التعريفات المعجمية في ملفك البحثي:

| حالة المقارنة | الإجراء |
|--------------|---------|
| تعريف AWN يطابق المعاجم | `retain_definition` |
| التعريف الكلاسيكي أوسع من AWN | `nuance_note: scope` — سجّل الفرق |
| تعريف AWN أدق علمياً من المعاجم | `retain` (AWN أدقّ) |
| التعريف خاطئ أو ركيك | `revise_definition` |

### تأليف التعريفات — Definition Authoring

> **الأساس النظري:** كتاب **«علم المصطلح»** (علي القاسمي، 2019، ص 787–808) والتوصية 704 للمنظمة الدولية للتقييس (إيزو).

#### أنواع التعريفات الثلاثة

| النوع | الرمز | الغرض | إلزامي؟ |
|---|---|---|---|
| **المصطلحي** | `terminological` | تعريف رسمي بالجنس والفصل | **دائماً** |
| **اللغوي** | `linguistic` | تعريف ميسَّر بالمرادفات أو السياق | **مستحسن** |
| **الموسوعي** | `encyclopedic` | سرد الخصائص الجوهرية والعرضية | **اختياري** (للمحسوسات) |

#### التعريف المصطلحي — Terminological Definition

**البنية:**

```
[الجنس القريب (= hypernym)] + [الفصل النوعي (= ما يميز عن الأشقاء)]
```

**كيف تبنيه:**

1. حدد المجموعة الأعم (hypernym) من بيانات المجموعة
2. **الجنس** = اللمّة أو التعريف العربي للمجموعة الأعم
3. **الفصل** = ما يميز هذا المفهوم عن أشقائه (co-hyponyms)

**مثال (مال / money):**

| | التعريف |
|---|---|
| **سيئ** ❌ | `الثروة المحسوبة من حيث المال` — دائري + ترجمة حرفية |
| **جيد** ✓ | `ثروة ذات قيمة نقدية يمكن التصرف بها في المعاملات التجارية` |

#### التعريف اللغوي — Linguistic Definition

> التعريف الذي يقوله متحدث عربي أصلي إذا سُئل «ما معنى X؟»

الأنماط الفرعية:

| النمط | الرمز | مثال |
|---|---|---|
| بالمرادف | `synonym` | الغضنفر: الأسد |
| بالنقيض | `antonym` | الكبير: عكس الصغير |
| بالمثال | `example` | حروف الجر: مثل مِن، على، إلى |
| بالاشتقاق | `derivation` | الحريري: مَن يبيع الحرير |
| بالسياق | `context` | عبارة تبيّن معنى اللفظ في سياقه |

**كيف تبنيه:** استخرج التعريفات من المعاجم في ملفك البحثي. ابحث عن قوائم المرادفات: «أي X و Y»، «الدَّنَس: الوسخ والقذر».

#### التعريف الموسوعي — Encyclopedic Definition

**متى يُستخدم:** اختياري. يُفضَّل للأسماء المحسوسة (حيوانات، نباتات، أدوات) والمفاهيم الثقافية.

**البنية:**

```
[خصائص جوهرية] + [خصائص عرضية بارزة] + [المجال أو سياق الاستعمال]
```

#### متى يكفي تعريف واحد؟

| الحالة | العدد |
|--------|------|
| لا شواهد معجمية متاحة | 1 (مصطلحي فقط) |
| اسم محسوس بسيط | 2 (مصطلحي + لغوي) |
| مفهوم مجرد أو فعل | 2 (مصطلحي + لغوي) |
| مفهوم معقد (حيوان، نبات) | 3 (الثلاثة) |

#### شروط الجودة الخمسة

> المصدر: القاسمي 2019، ص 804.

| الشرط | الرمز | السؤال |
|---|---|---|
| **الوضوح** | `clarity` | خالٍ من الغموض والألفاظ الغريبة؟ |
| **الإيجاز** | `conciseness` | كل كلمة ضرورية؟ |
| **التساوي** | `equivalence` | جامع مانع — لا زيادة ولا نقصان؟ |
| **الإيجاب** | `positive` | يعرّف ما هو الشيء، لا ما ليس هو؟ |
| **الخلو من اللغو** | `no_tautology` | يخلو من لفظ المعرَّف نفسه؟ |

#### العيوب الستة

> المصدر: القاسمي 2019، ص 805–806.

| العيب | الوصف | التصحيح |
|---|---|---|
| **الحشو** | تكرار معلومات في الجنس | احذف المكرر |
| **السطحية** | جنس بعيد جداً | استخدم الجنس القريب |
| **تعريف المجهول بالمجهول** | ألفاظ أندر من المعرَّف | استخدم وصفاً مفهوماً |
| **الدور** | A يُعرَّف بـ B و B بـ A | عرّف بخصائص مستقلة |
| **الإحالات المتسلسلة** | أكثر من إحالة للوصول للتعريف | عرّف مباشرة |
| **غياب المميزات** | لا يميّز معاني المشترك | أضف قيداً مميزاً |

## 2.5 الخطوة ٤: فحص العلاقات — Relations Check

### اختبار التعميم — Generalization Test

> هل X هو فعلاً نوع من Y؟

- إذا نعم ← `relations_ok` ✓
- إذا نعم تقنياً لكن هناك أعم أقرب ← `flag_relation` (اقترح البديل)
- إذا لا ← `flag_relation` (خطأ في التسلسل)

### فحوصات إضافية

- **التعدية وحروف الجر:** الفعل لا يُقبل إلا مقروناً بحرفه (رغب **في** ≠ رغب **عن**)
- **التفريق بين المصدر واسم الفاعل:** لا تخلط "الضحك" (الحدث) و"الضاحك" (الفاعل)
- **القيود الدلالية:** إذا كانت الكلمة تتطلب فاعلاً عاقلاً، اذكر القيد

## 2.6 الإثراء — Enrichment

لكل لمّة، املأ حقول الإثراء التالية:

| الحقل | الوصف | القيم |
|-------|------|------|
| `root` | الجذر المؤكَّد | مثال: `"ك ت ب"` |
| `usage` | وسم الاستخدام | `archaic` تراثي / `modern` معاصر / `common` شائع |
| `eloquence` | رتبة الفصاحة | `eloquent` فصيح / `neologism` مولَّد / `colloquial` مبتذل |
| `connotation` | الإيحاء النفسي | `positive` / `negative` / `reverential` / `pejorative` / `neutral` |
| `literal_figurative` | حقيقة أو مجاز | `literal` / `figurative` |
| `figurative_relation` | علاقة المجاز | مثال: `"العلوّ والتدبير"` |
| `nuance_note` | الفارق الدقيق (**إلزامي**) | نص حر يميز اللمّة عن أخواتها |
| `typical_collocate` | المتلازم الشائع | مثال: `"كتاب + مقدّس / نافع"` |
| `syntactic_frame` | القالب النحوي (أفعال) | مثال: `"[متعدٍ بنفسه]"` |
| `source` | المعجم الداعم | مثال: `"المعجم الوسيط"` |

### استخلاص الإثراء من النص المعجمي

| ماذا تبحث عنه في النص | الحقل في YAML | مثال |
|------|------|------|
| علامات المجاز: "من المجاز"، "ويُستعار لـ" | `literal_figurative` + `figurative_relation` | «ومن المجاز: تدنّس عرضه» ← `figurative` |
| الأنماط الفعلية: "فَعَلَ كذا بكذا" | `syntactic_frame` | «لوّث الشيءَ بالشيءِ» ← `[متعدٍ بنفسه + بـ]` |
| الفاعل/المفعول الشائع في الأمثلة | `typical_collocate` | «دنّس المكانَ» ← `مكان مقدس` |
| المشتقات من نفس الجذر | تأكيد `root` + مرشحات | جذر «د-ن-س»: دَنَس، دَنِس، تدنيس |
| علامات العصر: "مولَّد"، "محدث" | `usage` | «مولَّد» ← `modern` |
| علامات السجل: "عامي"، "مبتذل" | `eloquence` | «لفظ عاميّ» ← `colloquial` |
| قوائم المرادفات: "أي X و Y" | مرشحات `missing_lemmas` | «الدَّنَس: الوسخ والقذر» ← مرشحان |
| شواهد حقيقية بالمعنى المقصود | `examples` | شاهد شعري يستعمل الكلمة بالمعنى المطلوب |
| القيود الدلالية: "لا يُقال إلا لـ" | `nuance_note` | «الحفيف: لا يُقال إلا لصوت الشجر» |

## 2.7 التحقق الصرفي — Morphological Validation

| الفحص | ماذا تبحث عنه | الإجراء |
|-------|---------------|--------|
| **الجموع التكسيرية** | جمع مدرج كلمة مستقلة | اربطه بالمفرد |
| **التطبيع الإملائي** | خلط ى/ي، خلط ة/ه، تغيرات الألف | طبّع إلى الإملاء المعياري |
| **اللواصق** | حرف جر/عطف أو ضمير ملتحق | جرّد إلى الصيغة الأساسية |
| **التحقق من الجذر** | الجذر المُستنتج يطابق الشواهد | أكّد الجذر |
| **التسرب اللهجي** | شكل غير فصيح | استبدل بالمقابل الفصيح |

> **ملاحظة:** ≈41% من الأسماء العربية تستخدم جموعاً تكسيرية. الترجمة الآلية قد تدرجها كلمات مستقلة.

## 2.8 إرشادات حسب نوع الكلمة — POS-Specific Guidance

### الأسماء — Nouns

- تحقق من ربط الجمع التكسيري بالمفرد
- ميّز بين المصدر (عِلم، حُزن) واسم الذات (كتاب، شجرة)
- ميّز المصدر المطلق عن اسم المرة واسم الهيئة
- تحقق من أن أوزان المشتقات قياسية أو مسموعة
- تحقق من عدم الخلط بين أبنية من نفس الجذر (مَأْل ≠ مال)

### الأفعال — Verbs

- حدد إطار التعدية: `[لازم]` / `[متعدٍ بنفسه]` / `[متعدٍ بـ حرف]`
- **حرف المعنى يحدد المعنى**: (نظر **إلى** ≠ نظر **في**)
- انتبه لظاهرة **التضمين النحوي**
- اذكر المصدر والمتلازمات الشائعة
- حدد القالب النحوي (المتممات اللازمة)

### الصفات — Adjectives

- تحقق من تباين المعنى التراثي والمعاصر
- تحقق من اتساق الوزن الصرفي (فَعِيل، فَعُول، مِفْعال)
- استبدل التراكيب الركيكة (صفة + جداً) بصيغ المبالغة (فَعّال، مِفْعَال)
- ذكر صيغة التفضيل إن كانت ذات صلة

### الظروف — Adverbs

- لا يوجد في العربية صنف نحوي مستقل للظرف كالإنجليزية
- غالباً تُعبَّر بـ جار ومجرور (بسرعة) أو حال أو مفعول مطلق
- ابحث عن الاسم الأساسي: شواهد "بذكاء" ستكون تحت "ذكاء"

## 3.2 سلّم التقييم — Scoring Rubric

### الدقة الدلالية — Semantic Accuracy (0–3)

| الدرجة | الوسم | قاعدة القرار | مثال |
|--------|-------|-------------|------|
| **0** | خاطئ | لا يحمل هذا المعنى مطلقاً | «كتب» لمفهوم "to read" |
| **1** | صحيح جزئياً | يتقاطع مع المعنى لكنه أعمّ أو أضيق | «حيوان» لمفهوم "mammal" |
| **2** | صحيح غالباً | جوهر المعنى مع فروق طفيفة | «ذكي» لمفهوم "intelligent" |
| **3** | صحيح تماماً | تطابق دلالي تام | «شمس» لمفهوم "sun" |

> **تمييز 1 و2:** احتجت لإضافة قيد → **1**. تصلح في معظم السياقات مع تحفظات → **2**.

### جودة التعريف — Gloss Quality (0–3)

| الدرجة | الوسم | قاعدة القرار |
|--------|-------|-------------|
| **0** | مفقود/مبهم | لا تعريف، أو دائري أو غير مفهوم |
| **1** | ضعيف | ترجمة حرفية أو غير نحوي |
| **2** | مقبول | مفهوم وسليم لكن يمكن تحسينه |
| **3** | ممتاز | عربية طبيعية، بنية جنس-فصل |

> **تمييز 1 و2:** المتحدث الأصلي سيتجهّم → **1**. سيفهم لكن قد يعيد الصياغة → **2**.

### تماسك الترادف — Synonym Coherence (0–2)

| الدرجة | قاعدة القرار |
|--------|-------------|
| **0** | لمّة واحدة على الأقل ليست مرادفاً (تفشل في الإبدال) |
| **1** | جميعها ذات صلة لكن واحدة تحمل فارقاً واضحاً |
| **2** | جميعها تجتاز اختبار الإبدال |

### الاكتمال — Completeness (0–2)

| الدرجة | قاعدة القرار |
|--------|-------------|
| **0** | تنقص لمّتان أساسيتان أو أكثر |
| **1** | تنقص لمّة واحدة |
| **2** | المجموعة تضم الألفاظ الشائعة |

### التصنيف الثقافي — Cultural Adequacy

| القيمة | الوصف |
|--------|------|
| `direct` | تطابق مفاهيمي كامل |
| `near_synonym` | أقرب مقابل متاح مع تبيان الفرق |

## 3.5 أنماط أخطاء الترجمة الآلية — MT Error Patterns

| النمط | مثال (خطأ) | التصحيح |

## تدريب 1: مال — اسم شائع بتطور دلالي (money / wealth)

**المجموعة:** `awn4-13271441-n` — اللمّات: مال — التعريف: ثروة ذات قيمة نقدية

### المرحلة 1: البحث المعجمي

**الخطوة 1 — المطابقة الدقيقة:**

```sql
SELECT d.name_ar, d.death_year, d.period
FROM entries e
JOIN dictionaries d ON e.dictionary_id = d.id
WHERE e.headword_norm = 'مال'
ORDER BY d.death_year;
```

**النتيجة:** مداخل في معاجم كلاسيكية وحديثة — الكلمة مثبتة عبر القرون.

**الخطوة 2 — التعريفات الكاملة:**

```sql
SELECT d.name_ar, d.death_year, df.sense_index, df.text
FROM entries e
JOIN dictionaries d ON e.dictionary_id = d.id
JOIN definitions df ON df.entry_id = e.id
WHERE e.headword_norm = 'مال' AND e.pos = 'noun'
ORDER BY d.death_year, df.sense_index;
```

**اكتشاف مهم:** في لسان العرب (1311م)، المعنى الأول لـ «مال» هو **الإبل** (ما يملكه الإنسان من إبل)، ثم توسع ليشمل كل ثروة.

**الخطوة 3 — عائلة الجذر:**

```sql
SELECT e.headword_bare, e.pos, COUNT(DISTINCT d.id) AS dict_count
FROM entries e JOIN dictionaries d ON e.dictionary_id = d.id
WHERE e.root = 'مول'
GROUP BY e.headword_bare, e.pos ORDER BY dict_count DESC LIMIT 15;
```

**النتيجة:** مشتقات: تمويل، ممول، أموال.

**الخطوة 4 — الجسر الإنجليزي:**

```sql
SELECT e.headword_bare, e.translation_en, e.domain
FROM entries e
JOIN entries_translations_fts ON e.id = entries_translations_fts.rowid
WHERE entries_translations_fts MATCH '"money" OR "wealth" OR "capital"'
ORDER BY rank LIMIT 15;
```

**النتيجة:** مصطلحات: رأس المال، رصيد، نقد.

**الخطوة 5 — الشواهد القرآنية:**

```sql
SELECT e.headword_bare, ex.text
FROM entries e JOIN examples ex ON ex.entry_id = e.id
WHERE e.headword_norm = 'مال' AND ex.type = 'quran';
```

### المرحلة 2: التحليل اللغوي

**الخطوة 1 (تحقق):** «مال» مؤكَّدة ✓ — كل المعاجم تتفق.

**الخطوة 2 (مفقودات):** لا مرادفات مباشرة مفقودة. «نقود» أخص (عملات). «ثروة» أعم.

**الخطوة 3 (تعريف):** تطور دلالي مهم: مال = إبل → كل ثروة. يستحق `nuance_note`.

**الخطوة 4 (علاقات):** الأعلى منطقي.

**الحصيلة:**

| الإجراء | التفصيل |
|---------|---------|
| ✓ تأكيد | «مال» مؤكَّدة |
| `nuance_note` | تطور دلالي: إبل (كلاسيكي) → كل ثروة (حديث) |
| شاهد قرآني | يؤكد الاستعمال بالمعنى المالي |

## تدريب 2: شجرة — اسم محسوس (tree)

**المجموعة:** `awn4-13124818-n` — اللمّات: شجرة — التعريف: نبات خشبي معمر طويل له جذع رئيسي وفروع تشكل تاجاً

### المرحلة 1: البحث المعجمي

```sql
SELECT d.name_ar, d.period, d.death_year, e.pos, e.definitions_text
FROM entries e JOIN dictionaries d ON e.dictionary_id = d.id
WHERE e.headword_norm = 'شجر'
ORDER BY d.death_year;
```

**النتيجة:** 22 مدخلاً. كتاب العين: «من النبات ما له ساق». الوسيط: «نبتة ذات ساق صلبة».

**⚠️ ملاحظة:** الجذر ش-ج-ر متعدد المعاني — «شَجَرَ بينهم» = تنازعوا. لعزل المعنى النباتي:

```sql
SELECT e.headword_bare, e.pos, d.name_ar, SUBSTR(e.definitions_text, 1, 150)
FROM entries e JOIN dictionaries d ON e.dictionary_id = d.id
WHERE e.root = 'شجر' AND e.pos = 'noun'
ORDER BY d.death_year;
```

**البحث عن مرادفات مفقودة:**

```sql
SELECT e.headword_bare, d.name_ar, SUBSTR(e.definitions_text, 1, 200)
FROM entries e JOIN dictionaries d ON e.dictionary_id = d.id
JOIN entries_fts ON e.id = entries_fts.rowid
WHERE entries_fts MATCH 'definitions_text:"نبات" AND definitions_text:"ساق"'
  AND e.headword_bare <> 'شجر' AND d.source_type IN ('ocr', 'hawramani')
ORDER BY rank LIMIT 10;
```

**الشواهد القرآنية:**

```sql
SELECT e.headword_bare, ex.text, d.name_ar
FROM entries e JOIN examples ex ON ex.entry_id = e.id
JOIN dictionaries d ON e.dictionary_id = d.id
WHERE e.root = 'شجر' AND ex.type = 'quran';
```

**اكتشاف:** ﴿وَأَنْبَتْنَا عَلَيْهِ شَجَرَةً مِنْ يَقْطِينٍ﴾ — اليقطين متسلّق لا شجرة! التعريف الكلاسيكي أوسع.

### المرحلة 2: التحليل اللغوي

| الخطوة | النتيجة |
|--------|---------|
| ✓ تحقق | «شجرة» مؤكَّدة بإجماع المعاجم |
| مفقودات | لا مرادفات مفقودة |
| تعريف | الكلاسيكي «ما له ساق» أوسع — AWN أدق علمياً |
| علاقات | نبات خشبي = الأعلى ← منطقي |

**الحصيلة:**

| الإجراء | التفصيل |
|---------|---------|

## تدريب 3: حب / محبة — اسم مجرّد (love)

**⚠️ فخ تعدد المعاني:** النتائج مختلطة:

```sql
-- صفر نتائج!

SELECT d.name_ar, e.headword, e.definitions_text
```

## تدريب 4: كَتَبَ — فعل (to write/inscribe)

```sql
SELECT d.name_ar, df.sense_index, df.text
```

## تدريب 5: جميل / حسن / لطيف — صفة متعددة اللمّات (pleasant / beautiful)

**المجموعة:** `awn4-01590750-a` — اللمّات: جميل، حسن، لطيف — التعريف: سارّ أو مبهج

### المرحلة 1: البحث المعجمي

ثلاث لمّات من ثلاثة جذور (ج-م-ل، ح-س-ن، ل-ط-ف) — ثلاثة استعلامات مستقلة.

**جميل:**

```sql
SELECT d.name_ar, e.definitions_text
FROM entries e JOIN dictionaries d ON e.dictionary_id = d.id
```

**لطيف — اكتشاف مهم:**

```sql
SELECT d.name_ar, e.definitions_text
FROM entries e JOIN dictionaries d ON e.dictionary_id = d.id
WHERE e.headword_norm = 'لطيف' ORDER BY d.death_year;
```

**النتيجة:** الوسيط يعرّف أحدهما بالآخر — ترادف دائري مُثبت.

```sql
SELECT d.name_ar, d.death_year, d.period, d.source_type
FROM entries e JOIN dictionaries d ON e.dictionary_id = d.id

ORDER BY d.death_year;
```

**المتوقع:** معاجم حديثة و ARABTERM فقط — لا كلاسيكيات.

**عائلة الجذر (حسب):**

```sql
SELECT e.headword_bare, e.pos, COUNT(DISTINCT d.id) AS dict_count
FROM entries e JOIN dictionaries d ON e.dictionary_id = d.id
WHERE e.root = 'حسب'
GROUP BY e.headword_bare, e.pos
HAVING e.pos IN ('noun', 'verb')
ORDER BY dict_count DESC LIMIT 15;
```

**مصطلحات ARABTERM:**

```sql
SELECT e.headword_bare, e.translation_en, e.domain
FROM entries e
WHERE e.domain IN ('Dictionary of Information Technology Terms', 'Information and Communication')
  AND (e.headword_bare LIKE '%حاسوب%' OR e.headword_bare LIKE '%حاسب%'
       OR e.headword_bare LIKE '%كمبيوتر%')
ORDER BY e.headword_bare LIMIT 20;
```

| الإجراء | التفصيل |
