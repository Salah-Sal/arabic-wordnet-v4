# خوارزمية المرحلة الأولى — البحث المعجمي
# Stage 1 Algorithm — Dictionary Research

> هذه المرحلة تحوّل المراجع إلى **باحث**: ينفّذ استعلامات على قاعدة البيانات المعجمية ويجمع المادة في ملف بحثي منظّم.
> هذا الملف مستقل عن المرحلة الثانية. المخرج الوحيد هو **الملف البحثي** الذي تستهلكه المرحلة الثانية.

---

## الاصطلاحات — Conventions

```
لكل X في Y نفّذ          FOR EACH X in Y DO
إذا ... فـ               IF ... THEN
وإلا إذا ... فـ          ELSE IF ... THEN
وإلا                     ELSE
نهاية                    END
⟵                        تعيين (assignment)
▸ إجراء(هدف)             ورقة — إجراء نهائي ينفّذه المراجع
// تعليق                  ملاحظة توضيحية
┊                         مستوى التداخل (indentation = scope)
```

---

## المُدخل — Input

```
مجموعة_ترادفية = {
    معرّف:       "oewn-XXXXXXXX-X"          // synset ID
    لمّات:       [لمّة₁، لمّة₂، ...]         // Arabic lemmas (machine-translated)
    تعريف_عربي:  "..."                       // Arabic gloss
    تعريف_إنجليزي: "..."                     // English gloss (from OEWN)
    نوع:         اسم | فعل | صفة | ظرف       // POS
    علاقات:      [{نوع، هدف}, ...]           // hypernym, hyponym, etc.
}
```

---

## المُخرج — Output: الملف البحثي

> هذا هو **العقد** بين المرحلة الأولى والثانية.
> المرحلة الثانية تقرأ هذه الحقول فقط — لا تكتب إليها.

```
الملف_البحثي = {

    // لكل لمّة (مفتاح: اسم اللمّة)
    توثيق: {
        لمّة → {
            عدد_المعاجم:    عدد صحيح           // كم معجماً يوثّق هذه اللمّة
            الفترات_الزمنية: [كلاسيكي، وسيط، حديث]  // العصور التي ظهرت فيها
        }
    }

    تعريفات: {
        لمّة → [
            {
                مصدر:      اسم المعجم
                نص:        نص التعريف
                مطابق:     صحيح | خطأ         // هل يطابق المعنى المقصود في المجموعة
                تشويش:     "..."               // ملاحظة إن وُجد غموض
            }
        ]
    }

    عائلة_الجذر: {
        جذر:        "..."                      // الجذر الثلاثي/الرباعي
        مشتقات:     [كلمة₁، كلمة₂، ...]
        مرشحات:     [مرشح₁، مرشح₂، ...]       // مشتقات تحمل نفس المعنى — مرشحة كمرادفات
    }

    شواهد: {
        لمّة → [
            {
                نوع:       quran | hadith | poetry | prose
                نص:        "..."
                بالمعنى:   صحيح | خطأ         // هل الشاهد بالمعنى المقصود
            }
        ]
    }

    تطور_زمني: {
        لمّة → {
            تصنيف:     مستقر | توسيع_دلالي | تضييق_دلالي | انزياح_دلالي
                       | تراثي_فقط | حديث_فقط
        }
    }

    مرشحات_المرادف: [                         // مجمّعة من: عائلة الجذر + FTS + البحث العكسي
        {
            كلمة:      "..."
            المصدر:    root_family | fts | reverse_lookup
            ملاحظة:    "..."
        }
    ]

    arabterm: [                                // من entries_translations_fts
        {
            مصطلح_عربي:  "..."
            مصطلح_أجنبي: "..."
            المجال:      "..."
            تهجئة_بديلة: "..."
        }
    ]
}
```

## الخوارزمية

```
لكل مجموعة_ترادفية في قائمة_المراجعة نفّذ

    الملف_البحثي ⟵ ملف_فارغ(مجموعة_ترادفية.معرّف)

    // ══════════════════════════════════════════════
    // الخطوات التي تُنفَّذ لكل لمّة على حدة
    // ══════════════════════════════════════════════

    لكل لمّة في مجموعة_ترادفية.لمّات نفّذ

        // الخطوة ١: المطابقة الدقيقة
        ▸ استعلم(headword_norm = لمّة)
        ▸ سجّل(الملف_البحثي.توثيق، عدد_المعاجم، الفترات_الزمنية)

        // الخطوة ٢: التعريفات الكاملة
        ▸ استعلم(definitions JOIN entries WHERE headword_norm = لمّة)
        ▸ سجّل(الملف_البحثي.تعريفات، التعريفات_المطابقة_للمعنى، التشويش)

        // الخطوة ٣: عائلة الجذر
        جذر ⟵ استنتج_الجذر(لمّة)      // ← انظر الإجراء الفرعي أدناه
        ▸ استعلم(root = جذر)
        ▸ سجّل(الملف_البحثي.عائلة_الجذر، المشتقات، مرشحات_المرادف)

        // الخطوة ٦: الشواهد
        ▸ استعلم(examples WHERE headword_norm = لمّة AND type IN [quran, hadith, poetry])
        ▸ سجّل(الملف_البحثي.شواهد، الشواهد_بالمعنى_المقصود_فقط)

        // الخطوة ٧: التطور الزمني
        ▸ استعلم(definitions ORDER BY death_year WHERE headword_norm = لمّة)
        إذا لمّة_في_الكلاسيكي_فقط فـ
            ▸ سجّل(تراثي_فقط)
        وإلا إذا لمّة_في_الحديث_فقط فـ
            ▸ سجّل(حديث_فقط — مرشح_كمولّد)
        وإلا إذا المعنى_الكلاسيكي ≠ المعنى_الحديث فـ
            إذا المعنى_الكلاسيكي أضيق فـ
                ▸ سجّل(توسيع_دلالي)
            وإلا إذا المعنى_الكلاسيكي أوسع فـ
                ▸ سجّل(تضييق_دلالي)
            وإلا
                ▸ سجّل(انزياح_دلالي)
            نهاية
        وإلا
            ▸ سجّل(مستقر_عبر_العصور)
        نهاية

        // الخطوة ٨: البحث العكسي عن مرشحات المرادف
        ▸ استعلم(entries_fts MATCH definitions_text:لمّة AND headword ≠ لمّة)
        ▸ سجّل(الملف_البحثي.مرشحات_المرادف)

    نهاية  // لكل لمّة

    // ══════════════════════════════════════════════
    // الخطوات على مستوى المجموعة
    // ══════════════════════════════════════════════

    // الخطوة ٤: البحث النصي الكامل (FTS5)
    كلمات_مفتاحية ⟵ استخلص_مفاتيح(مجموعة_ترادفية.تعريف)
    ▸ استعلم(entries_fts MATCH كلمات_مفتاحية)
    إذا النتائج قليلة فـ
        ▸ وسّع(استخدم OR، أضف مرادفات)
    وإلا إذا النتائج كثيرة فـ
        ▸ ضيّق(أضف NOT، فلتر pos أو domain)
    نهاية
    ▸ سجّل(الملف_البحثي.مرشحات_المرادف، كلمات_متقاطعة)

    // الخطوة ٥: الجسر الإنجليزي (ARABTERM)
    ▸ استعلم(entries_translations_fts MATCH مجموعة_ترادفية.تعريف_إنجليزي)
    إذا المصطلح_الإنجليزي متعدد_المعاني فـ
        ▸ ضيّق(أضف فلتر domain)
    نهاية
    ▸ سجّل(الملف_البحثي.arabterm، مصطلحات_تقنية، تهجئات_بديلة)

    // الخطوة ٩: التصفية التخصصية (حسب الحاجة)
    إذا الجذر_متعدد_الأصناف فـ
        ▸ استعلم(root = جذر AND pos = الصنف_المطلوب)
    نهاية
    إذا المجال_تخصصي فـ
        ▸ استعلم(source_type = 'arabterm' AND domain = المجال)
    نهاية

    ▸ أغلق(الملف_البحثي)
    // ═══ انتهت المرحلة الأولى — الملف البحثي جاهز ═══

نهاية  // لكل مجموعة ترادفية
```

## الإجراء الفرعي: استنتج_الجذر

```
دالة استنتج_الجذر(لمّة):

    // الطريقة ١: البحث في قاعدة البيانات
    نتائج ⟵ استعلم(SELECT DISTINCT root, root_source WHERE headword_norm = لمّة)
    إذا نتائج غير فارغة فـ
        إذا مصادر متعددة ومتعارضة فـ
            جذر ⟵ الأولوية: lane ثم ocr ثم camel
        وإلا
            جذر ⟵ نتائج[0].root
        نهاية
        أعد جذر

    // الطريقة ٢: التجريد الصرفي
    وإلا إذا لمّة تطابق وزناً معروفاً فـ         // تَفْعِيل، اسْتِفْعال، مُفاعَلة، ...
        جذر ⟵ جرّد_حسب_الوزن(لمّة)
        // تحقق بالطريقة ١ بعد الاستنتاج
        تأكيد ⟵ استعلم(root WHERE headword_norm IN مشتقات(جذر))
        إذا تأكيد فـ
            أعد جذر
        نهاية

    // الطريقة ٣: الاستنتاج اللغوي المباشر
    وإلا
        جذر ⟵ جرّد_الزوائد_يدوياً(لمّة)   // سألتمونيها → حدّد الأصول
        أعد جذر
    نهاية

نهاية_الدالة
```

## فهرس إجراءات المرحلة الأولى (▸)

| الإجراء | الوصف |
|---------|------|
| `▸ استعلم(...)` | تنفيذ استعلام SQL على قاعدة البيانات المعجمية |
| `▸ سجّل(حقل، ...)` | تسجيل النتيجة في الحقل المناسب من الملف البحثي |
| `▸ وسّع(...)` | توسيع استعلام FTS5 (OR، مرادفات) عند قلة النتائج |
| `▸ ضيّق(...)` | تضييق استعلام FTS5 (NOT، فلتر) عند كثرة النتائج |
| `▸ أغلق(الملف_البحثي)` | إغلاق الملف البحثي — جاهز للمرحلة الثانية |
